# Agent Infra Digest, 2026-10-26

## 1. Claude Code ships MCP Tasks and Elicitations for durable, interruptible tool work
[Forkast](https://forkast.news/claude-ships-mcp-tasks-and-elicitations-in-claude-code-durable-agent-workflows-narrow-launch/)
Why it matters: long MCP tools can now return a task id instead of blocking, and a tool can pause to ask the user a question mid-run, which turns MCP from single request/response calls into background jobs with consent built in.

## 2. OpenAI pushes Codex from coding agent to office workbench with six role plug-ins
[NewAICodes](https://newaicodes.com/news/openai-codex-tools-office-worker)
Why it matters: with more than 5 million weekly active users and knowledge workers as its fastest growing segment, Codex is now packaged for analytics, sales, design, and finance workflows, which means harness builders must compete on finished work products, not just code edits.

## 3. A planted AGENTS.md file can hijack Claude Code and Codex from the Downloads folder
[Martincid](https://www.martincid.com/technology-sv/agents-md-downloads-folder-hijack-claude-code-codex/)
Why it matters: researchers found that an instructions file dropped by a website can steer an agent that reads its startup folder, which makes the working directory and untrusted instruction files a security boundary, not just a convenience.

## 4. Wake 0.10.2 unifies search and resume across Claude Code, Codex, Cursor, and Gemini CLI sessions
[Wake](https://wake.cool/)
Why it matters: a local, read-only app that indexes every agent session on disk and resumes any of them, plus a bundled wake-mcp server, is exactly the session handoff layer LegCli cares about, built without accounts or telemetry.

## 5. Nous raises $17M for a household agent that manages bills, spending, and admin
[Dealroom](https://dealroom.co/news/165728-monzo-founder-tom-blomfield-backs-ai-agent-startup-nous-in-17m-round/)
Why it matters: Heartcore Capital led the round with founders from Monzo, GoCardless, Faculty, and Onfido joining, which shows operator money is now backing consumer agents that take real actions on money, not just chat about it.

## 6. Strawberry launches 1.0 of its agent browser platform for non-technical teams
[Retail Technology Innovation Hub](https://retailtechinnovationhub.com/home/2026/10/26/swedish-startup-strawberry-launches-ai-agent-platform-and-preps-series-a-funding-round)
Why it matters: team-shared AI companions that remember how a team works, built inside the browser where logins and context already live, test whether agent adoption comes from shared memory rather than a better single-user prompt.

## 7. fileAI signs an AWS collaboration deal for outcome-driven agents in banking and insurance
[WCIA](https://www.wcia.com/business/press-releases/cision/20261025CN78776/fileai-signs-strategic-collaboration-agreement-with-aws-to-accelerate-rollout-of-outcome-driven-ai-agents-for-bfsi-leaders/)
Why it matters: built on Bedrock and sold through AWS Marketplace, fileAI pairs repeatable skills with governed file intelligence to carry whole workflows to completion, which is the enterprise pattern where agents are judged on outcomes, not demos.

## 8. GitHub Copilot default-availability rollout runs through October 26, including MCP servers in Copilot
[AiCybr](https://aicybr.com/blog/github-copilot-feature-defaults-october-2026-enterprise-mcp-policy)
Why it matters: unconfigured Copilot features, code review policy, and MCP server policy now inherit the org default, so a permissive default can quietly enable MCP servers while a restrictive one keeps them off, and admins must inventory the effective state.

## 9. Moonshot resets 25% of Kimi quotas after K3.1 Pro launch burned usage on sub-agent calls
[Lapaas Voice](https://lapaasvoice.com/moonshot-ai-offers-25-quota-reset-after-kimi-k3-1-pro-launch-issues/)
Why it matters: unnecessary sub-agent calls and overlong outputs caused rate limits and surprise consumption, which is a public reminder that multi-agent loops need usage budgets and output caps before they ship, not after users complain.

## 10. Tipalti launches an AP Agent that runs accounts payable end to end, with MCP links to live finance data
[GenZ NewZ](https://genznewz.com/tipalti-ap-agent-runs-end-to-end-accounts-payable)
Why it matters: invoices, coding, approvals, payments, and reconciliation as one agent workflow, with human oversight, shows finance as the proving ground where agents must be explainable, auditable, and stoppable before they are trusted with real money.
