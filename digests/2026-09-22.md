# Agent Infra Digest, 2026-09-22

## 1. MCP gets its biggest update ever: stateless architecture, hardened auth, async tasks
[VentureBeat](https://venturebeat.com/infrastructure/mcp-just-got-its-biggest-update-ever-heres-what-changes-for-ai-agents)
Why it matters: Fully stateless MCP removes the "sticky routing" burden, so MCP servers now run behind standard load balancers and Kubernetes tooling. This is the change that makes enterprise-scale agent deployments operationally boring, which accelerates everything built on the protocol.

## 2. Claude Code now reads AGENTS.md
[InfoWorld](https://www.infoworld.com/article/4224410/claude-code-now-also-accepts-instructions-in-openais-agents-md-format.html)
Why it matters: Anthropic ended the CLAUDE.md versus AGENTS.md split. One shared instruction file across coding agents means repos (and handoff products) can standardize agent context instead of maintaining per-agent files.

## 3. Trading Central launches an official MCP server for financial research
[Business Wire](https://www.businesswire.com/news/home/20260921817927/en/Trading-Central-Launches-MCP-Server-to-Power-Financial-AI-Agents-Chatbots-with-Trusted-Research)
Why it matters: Another licensed, regulated data provider now exposes its catalog as an MCP server after a six-month soft launch, so "MCP server" is becoming the default distribution shape for proprietary data sold to AI agents.

## 4. Unity ships official Claude Code and Codex plugins
[Renascence](https://www.renascence.io/news/72594/unity-launches-official-claude-code-codex-plugins-for-developers)
Why it matters: A major platform now ships first-party coding-agent plugins to ground agents in current documentation, a pattern that turns documentation into agent infrastructure and rewards products with machine-readable context.

## 5. WSO2's Agent Manager goes GA: open control plane for agent governance
[TechTrendsKE](https://techtrendske.co.ke/2026/09/16/wso2-launches-open-platform-to-rein-in-enterprise-ai-agent-sprawl/)
Why it matters: Fully open source, framework-agnostic governance (identity, MCP-level policy, sandboxed runtime) is now GA, so agent governance is separating into its own infra layer rather than living inside each framework.

## 6. Cohesity launches Agent Resilience: backup and recovery for agent infrastructure
[Business Wire](https://www.businesswire.com/news/home/20260916951865/en/Cohesity-Introduces-Agent-Resilience-to-Protect-and-Recover-AI-Agent-Infrastructure)
Why it matters: Point-in-time recovery for agent memory and configuration plus protection of the databases agents touch. Governance and observability tools detect bad agent actions; this one rolls them back, which is the missing half of enterprise agent ops.

## 7. Tencent's Team Memory beta shares agent memory across a team
[VentureBeat](https://venturebeat.com/data/tencents-team-memory-shares-ai-agent-memory-across-a-team-with-no-governance-yet-for-when-its-wrong)
Why it matters: The memory problem is moving from "one agent remembers its session" to "a team of agents shares a governed memory hub," with an access control layer deciding who reads what. This is exactly the LegCli problem space, and a major cloud player just made it a trending open-source repo.

## 8. Symbiotic Security raises $10M for a "secure-by-design" coding agent
[Axeleo](https://www.axeleo.com/blog/symbiotic-security-raises-10m-and-launches-the-worlds-first-secure-by-design-ai-coding-agent/)
Why it matters: Instead of scanning code after generation, the agent embeds security policy as a generation constraint. If security-as-constraint wins over security-as-check, coding agent architectures shift toward policy-aware generation pipelines.

## 9. Google Home opens smart home control to third-party AI agents via MCP
[The Outpost](https://theoutpost.ai/news-story/google-home-unlocks-third-party-ai-agents-through-model-context-protocol-integration-30945/)
Why it matters: MCP is now the protocol by which agents get write access to physical infrastructure (locks, thermostats, cameras), which makes MCP-level permission and audit controls a production safety problem, not a developer-experience one.
