# Agent Infra Digest, 2026-09-17

## 1. Google lets engineers use Claude for coding as Gemini remains the default
[TechRepublic](https://www.techrepublic.com/article/news-google-claude-internal-coding-gemini/)
Why it matters: Even Google is going multi-model internally, expanding Claude Opus 5 access through its Antigravity platform with per-engineer quotas while Gemini stays primary. The multi-model coding-agent stack is becoming the enterprise norm, which favors tooling that works across harnesses.

## 2. Coder brings Claude Code to Agent Relay for regulated enterprises
[ittech-pulse](https://ittech-pulse.com/news/coder-brings-claude-code-to-agent-relay-for-regulated-enterprises/)
Why it matters: Claude Code can now run inside a customer's own cloud, VPC, or on-prem environment under platform-set network egress policy with full audit logging, opening financial services and other regulated orgs. Enterprise agent adoption is increasingly gated on deployment controls, not model capability.

## 3. Anthropic merges Claude chat and Cowork into one interface
[TechCrunch](https://techcrunch.com/2026/09/16/anthropic-merges-claude-chat-and-cowork-in-one-interface/)
Why it matters: One front end now routes chat, Cowork, Artifacts, and Design automatically, building on Cowork's recent memory-layer upgrade that carries context across chats. Anthropic is converging chat and agentic work into a single continuous assistant, which raises the baseline for what users expect from session continuity.

## 4. llm-wiki: local-first agent memory for multi-tool workflows
[GitHub](https://github.com/ekgardt/llm-wiki)
Why it matters: A Markdown vault plus session capture shared across OpenCode, Claude Code, Codex, and Cursor, with lifecycle hooks feeding one common memory layer. The indie ecosystem is converging on local-first, vendor-neutral agent memory, which is exactly the session-handoff problem space.

## 5. AIUC raises $40M Series A to build an underwriting layer for AI agents
[Tech Startups](https://techstartups.com/2026/09/15/venture-capital-startup-funding-roundup-september-15-2026-alumni-ventures-lightscape-partners-kleiner-perkins-khosla-ventures-sequoia-capital-more/)
Why it matters: Founded by Anthropic's first product hire and a former McKinsey partner and METR COO, AIUC's AIUC-1 standard evaluates agents against roughly 5,000 risk and attack combinations, with Cursor, ElevenLabs, Harvey, and UiPath already certified. Agent assurance is becoming its own infrastructure category.

## 6. TypeSafe AI raises $40M seed from DCVC
[Tech Startups](https://techstartups.com/2026/09/15/venture-capital-startup-funding-roundup-september-15-2026-alumni-ventures-lightscape-partners-kleiner-perkins-khosla-ventures-sequoia-capital-more/)
Why it matters: A $40M seed for foundation models and AI infrastructure tooling shows investors are still funding the base layer under agents, not just agent apps. Infra rounds keep getting larger even as the app layer crowds.
