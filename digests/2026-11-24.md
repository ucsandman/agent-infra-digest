# Agent Infra Digest, 2026-11-24

## 1. Sierra raises $1.75B Series F at a $30B valuation for enterprise customer-service agents
[The SaaS News](https://www.thesaasnews.com/news/sierra-raises-1-75b-series-f/)
Why it matters: led by Greenoaks and Lightspeed, the round comes with Sierra reporting over $400M in ARR after just two and a half years, which makes customer-facing agents the largest proven revenue story in the agent economy so far.

## 2. OX Security finds prompt injection in 22% of flagged MCP servers, and 83% cannot be verified
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261123ny04555/ai-agents-are-taking-orders-from-strangers-ox-security-research-finds)
Why it matters: across 542,207 components, poisoned tools outranked install-time malware as the attack vector, and nearly a third of MCP servers had no identifiable owner, so the MCP supply chain problem is now measured, not hypothetical.

## 3. AWS WAF now discovers and protects LLM, MCP, and A2A endpoints with Bedrock Guardrails
[AWS News](https://aws-news.com/article/2026-11-23-aws-waf-announces-automated-discovery-and-protection-for-llm-mcp-and-a2a-endpoints-using-amazon-bedrock-guardrails)
Why it matters: the new API Portal finds shadow MCP and A2A servers behind load balancers and CloudFront, and the AI Security rule group blocks malformed protocol messages and screens content for prompt injection, so undocumented agent endpoints are now a WAF problem, not an inventory problem.

## 4. PagerDuty MCP Server reaches general availability
[Releases](https://releases.fru.dev/companies/pagerduty)
Why it matters: the hosted remote server brings incident triage, investigation, and resolution into Claude, Cursor, and other MCP clients with no local install, while the self-hosted version is deprecated, so on-call work moves into the agent harness as a managed service.

## 5. OutSystems pairs its MCP server with AWS Transform for agentic legacy modernization
[OutSystems](https://www.outsystems.com/blog/posts/agentic-legacy-modernization)
Why it matters: the toolkit lets coding agents in Claude, Cursor, Codex, or Kiro read enterprise context over MCP while AWS Transform decodes COBOL into specs the platform rebuilds as governed apps, which turns legacy modernization into an agent workflow instead of a rewrite project.

## 6. DataGroomr launches an MCP server for Salesforce data quality
[PR Newswire](https://www.prnewswire.com/news-releases/datagroomr-introduces-mcp-server-to-bring-salesforce-data-quality-management-into-ai-assistants-302948239.html)
Why it matters: the server lets agents find and fix dirty CRM data through natural language inside Agentforce, Claude, and ChatGPT, and it is listed in Claude's Connectors Directory, so data quality is becoming an agent-callable capability rather than a batch job.

## 7. Embo raises a $110M seed led by a16z for a unified robot brain
[TSN Media](https://tsnmedia.org/embo-110m-seed-a16z-robot-brain/)
Why it matters: led by Andreessen Horowitz with Khosla, DST Global, and Nvidia, the round backs Dreamer creator Danijar Hafner building a single world model for humanoid robots, which puts physical AI's biggest seed yet behind one model instead of one robot.

## 8. Codex CLI 0.172.0 adds cross-session thread links and Bedrock Runtime support
[Releases](https://releases.fru.dev/tags/mcp)
Why it matters: thread links let agents follow saved conversations and nested agents from search results and transcripts in the terminal, and Bedrock Runtime support widens where Codex can run, so session continuity keeps getting cheaper to maintain.

## 9. Claude Code 2.1.331 ships Code Mode across Bedrock, Google Cloud, and Microsoft Foundry
[BeevR](https://beevr.ai/blog/terminal-ai-coding-agents)
Why it matters: the November 23 release extends Code Mode to third-party providers with standardized OIDC groups and stronger api doctor diagnostics, so the experimental JavaScript tool-calling mode is now usable wherever enterprises already run Claude.

## 10. Audit finds Claude Agent SDK is MIT on PyPI but all rights reserved on npm
[DEV](https://dev.to/sarathkavuru/ai-agent-framework-licenses-claude-agent-sdk-is-mit-on-pypi-but-all-rights-reserved-on-npm-17-1bo1)
Why it matters: across 17 framework installs and 358 distributions, no GPL dependencies turned up, but the same SDK ships under different licenses per registry and CrewAI's packages carry no license text at all, which is a compliance trap for anyone vendoring agent frameworks into commercial products.
