# Agent Infra Digest, 2026-10-19

## 1. Claude Code 2.1.293 to 2.1.302: idle compaction, fork subagents by default, fail-closed hooks
[DEV Community](http://dev.to/akaranjkar08/claude-code-21293-to-21302-settings-worth-enabling-now-4job)
Why it matters: eight releases between October 7 and 16 made context management a versioned product feature: 200K+ token sessions compact after about 54 idle minutes, fork subagents are on by default in headless mode, hooks run at most 12 at a time, and onFailure: "block" turns a security hook from advisory into a real guardrail.

## 2. Claude Code now speaks the MCP 2025-11-25 spec, including URL prompts for sign-in
[releasebot.io](https://releasebot.io/updates/anthropic/claude-code)
Why it matters: sign-in becomes a first-class MCP primitive with URL prompts from MCP servers, but servers must declare "bareElicitationCapability": true or they stop connecting, so MCP server developers have a breaking migration to make.

## 3. Claude Design, Slides, and Docs now work inside Claude Code
[AI Catchup](https://aicatchup.com/news/claude-code-design-slides-docs-artifacts)
Why it matters: a coding session can now produce an editable design review deck, mockup, or document from the same files and RFCs it just worked on, collapsing the gap between writing code and shipping the artifacts that explain it.

## 4. Claude Code v2.1.300 started GZIP-compressing API requests
[DEV Community](http://dev.to/bargan/claude-code-added-gzip-in-2026-why-not-brotli-p7)
Why it matters: a community measurement showed one request shrinking from 594,750 to 289,145 bytes, about 51%, and the author estimates roughly 185 MB of avoided uploads over three hours, which shows latency and cost wins for agentic coding are coming from transport engineering, not bigger models.

## 5. Flavio Copes: how to document project decisions for coding agents
[flaviocopes.com](https://flaviocopes.com/project-decisions/)
Why it matters: published today, the guide argues projects should record decisions, rejected alternatives, and the constraints behind them so a future agent can pick up work without replaying dead ends, the same shape that useful session handoffs need.

## 6. Precedent: a decision graph from git history that coding agents check before editing
[Medium](https://medium.com/@sharma.shantam.321/the-context-your-coding-agent-never-sees-a-decision-graph-with-falkordb-7055fab960cc)
Why it matters: the project turns git history into a FalkorDB decision graph recording what was decided, why, by whom, and since when, tested on 45,240 real commits with 8 false alarms, moving reason-tracking from prose docs into queryable infrastructure.

## 7. Practitioner guide to context windows and agent memory: prefer fresh lookups over recalled facts
[DEV Community](http://dev.to/tdk-cli/everything-you-need-to-know-about-context-windows-and-agent-memory-16pg)
Why it matters: the October 18 guide lays out the working playbook for session memory: short sessions, durable instruction files, re-verify instead of trust, and treat stale memory as worse than none, a useful checklist for anyone building continuity layers.
