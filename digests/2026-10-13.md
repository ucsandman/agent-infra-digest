# Agent Infra Digest, 2026-10-13

## 1. Meta launches Muse Wonder and Muse Wonder Full, its first frontier-class agent models
[aidailypost.com](https://aidailypost.com/news/meta-launches-its-first-frontier-ai)
Why it matters: Released October 12 by Meta Superintelligence Labs with "Active Memory" (context carried across conversations) and "Active Focus," priced at $4/$20 per million tokens with a 1M context window and closed weights, so memory is moving from harness feature into the model itself, right in the session-continuity problem space.

## 2. DXC and LangChain partner on governed agent harnesses for mission-critical IT
[morningstar.com](https://www.morningstar.com/news/pr-newswire/20261013to70431/dxc-and-langchain-advance-agentic-ai-harnesses-for-mission-critical-it-operations)
Why it matters: DXC's OASIS platform, built on LangGraph and now licensed with LangSmith, is scaling toward 125 customer environments with a claimed 95% cut in resolution time, another sign that regulated enterprises are standardizing on governed agent harnesses rather than raw model calls.

## 3. Vercel's open-source agent framework eve is in public preview
[tsnmedia.org](https://tsnmedia.org/vercel-eve-open-source-agent-framework-public-preview-filesystem-first-durable-agents/)
Why it matters: eve is Apache-2.0 with sandboxed code execution, approval steps, and subagents, and Vercel says it already runs more than a hundred production agents, giving teams a self-hostable durable-agent framework outside the big labs, though docs still flag it as beta.

## 4. CellCog ships subagents that delegate to Claude Code, Codex, and Cursor on your own machine
[cellcog.ai](https://cellcog.ai/blog/ai-employee-subagents/)
Why it matters: An AI employee can now spawn a child coding agent through your own Claude, ChatGPT, or Cursor login and plan, so session delegation and its billing move to the user's local environment instead of the vendor's cloud, a pattern worth watching for LegCli-style session tooling.

## 5. Codex CLI 0.162 and Claude Code 2.1.296 land the same week; JetBrains answers with open-weight Mellum 2.1
[tech-insider.org](https://tech-insider.org/codex-cli-0-162-vs-claude-code-2-1-296-2026/)
Why it matters: OpenAI ships managed git worktree tools with GPT-6.1 Sol as the default (near-flagship coding at a fifth of the token price), Anthropic adds workflow-level subagent model pinning, and JetBrains releases a 12B open-weight MoE coding model, so the terminal-agent fight is now about cost, worktrees, and open weights.

## 6. Anthropic and AWS push server-side agent orchestration while Microsoft sunsets AutoGen
[aiagentstore.ai](https://aiagentstore.ai/ai-agent-news/topic/coding)
Why it matters: Anthropic's Managed Agents gain beta dynamic workflows with server-side multi-phase runs and workflow_run events, AWS Bedrock AgentCore adds tool-call lifecycle hooks, a Consent Portal, and TypeScript framework evals, and Microsoft puts AutoGen in maintenance mode pointing to Microsoft Agent Framework, so enterprise orchestration is consolidating onto vendor platforms.

## 7. Sierra publishes the Personal Agent Protocol draft and adds 35 design partners including OpenAI
[techstartups.com](https://techstartups.com/2026/10/09/top-ai-news-stories-this-week-october-5-9-2026/)
Why it matters: The "Poppy" draft published October 9 brought in OpenAI, PayPal, Mastercard, Visa, Bank of America, and Cloudflare alongside Meta, Shopify, Stripe, and Walmart, so the agent-commerce identity and permissions standard is gaining the participants that make real transactions possible.

## 8. Runtype preinstalls Claude Code and Codex in agent sandboxes
[runtype.com](https://www.runtype.com/changelog/claude-code-codex-agent-sandboxes)
Why it matters: Coding agents now ship inside the sandbox Linux computer with managed model access and no provider keys in the container, so running Claude Code or Codex inside an agent's execution environment is becoming default infrastructure, not an integration project.

## 9. CrowdStrike attributes South Korean bank intrusions to a China-based actor using the ARTEX agentic pentesting framework
[tech-insider.org](https://tech-insider.org/south-korea-bank-hacks-ai-agent-crowdstrike-2026/)
Why it matters: CrowdStrike ties the campaign that exposed roughly 68,000 bank records to the open-source ARTEX framework paired with Claude Code, the first major attributed case of autonomous agents inside a real intrusion chain, so agent guardrails and audit trails are now a defensive necessity.

## 10. Nous Research confirms $1.5B valuation on a $90M Series B for open-source agent work
[techcrunch.com](https://techcrunch.com/2026/10/07/nous-research-confirms-it-hit-1-5b-valuation-launches-ai-agents-for-business-users/)
Why it matters: Led by Robot Ventures with Nvidia, Union Square, Menlo, and Samsung in, and with the open-source Hermes Agent reportedly cloned 24M times and driving about 2.5% of global AI token usage, the raise funds a "Hermes for Businesses" enterprise push, showing investors will pay up for independent open agent models.
