# Agent Infra Digest, 2026-11-20

## 1. Anthropic debuts on Nasdaq in the largest IPO in history
[Investopedia](https://www.investopedia.com/anthropic-ipo-live-blog-ant-stock-12264678)
Why it matters: ANT opened at $111.50, closed at $97.17, up 17 percent on its $83 price, after raising $81.3 billion, so the company behind Claude Code and MCP is now a public-market bellwether for the whole agent stack.

## 2. Linq raises $90M led by Andreessen Horowitz to build agent infrastructure
[PR Newswire](https://www.prnewswire.com/news-releases/linq-raises-90-million-in-new-funding-led-by-andreessen-horowitz-to-build-the-infrastructure-platform-for-ai-agents-302944728.html)
Why it matters: the round funds messaging, computer use, and voice calling for agents on Linq's platform, with Ben Horowitz joining the board, which is another large bet that the agent layer needs its own infrastructure, not just models.

## 3. Metano emerges from stealth with $12M to secure AI agents across the enterprise
[Morningstar](https://www.morningstar.com/news/accesswire/1253435msn/metano-emerges-from-stealth-to-unify-ai-agent-security-across-the-enterprise)
Why it matters: led by Sierra Ventures, the platform discovers approved and unapproved agents, MCP servers, and skills, then watches behavior through a real-time context graph, so agent security is now a funded category with its own research lab.

## 4. Kong's Volcano agent cloud goes live with self-healing repairs
[Volcano](https://volcano.dev/blog/introducing-volcano-agent-cloud)
Why it matters: the cloud bundles durable workflows, branchable Postgres, edge functions, and hosting that coding agents can deploy to directly, while LavaFlow diagnoses production errors and proposes fixes, so the API gateway vendor is now selling the runtime agents live in.

## 5. OpenAI's Performance Factory puts Codex agents on ChatGPT regressions
[VentureBeat](https://venturebeat.com/orchestration/exclusive-openai-reveals-performance-factory-a-codex-powered-software-optimization-system-that-keeps-chatgpt-fast)
Why it matters: the internal system ran more than 1,700 automated investigations in three months and root-caused over 600, with an adversarial Codex reviewer challenging a quarter of diagnoses, and only 15 fixes shipped exactly as written, which is the honestest production data yet on where agent autonomy stops.

## 6. Google launches Gemini 4 Neon, the fast orchestrator of the Gemini 4 family
[Google Blog](https://blog.google/intl/en-in/products/introducing-gemini-4-neon/)
Why it matters: Neon ranks first on the Artificial Analysis Coding Agent Index at $3/$15 per million tokens with a 1M-token window, and Google positions it as the orchestrator directing parallel Hydrogen subagents in Antigravity, so the multi-model agent workflow now has a named middle tier.

## 7. Microsoft IQ lets agents inherit governed enterprise context
[Microsoft Tech Community](https://techcommunity.microsoft.com/blog/microsoft_365blog/whats-new-in-work-iq-at-ignite-2026-agents-that-get-work-done/4572219)
Why it matters: Work IQ is now generally available, unifying Microsoft 365, Dynamics 365, Fabric, Foundry, and web context with memory that carries across sessions, so agents stop rebuilding company knowledge per task and IT gets one governed path to it.

## 8. AWS lets AgentCore agents buy Marketplace products on the AWS bill
[Unite.AI](https://www.unite.ai/aws-lets-agentcore-agents-buy-marketplace-products-through-aws-billing/)
Why it matters: agents can now discover x402-enabled Marketplace listings and pay per request in dollars through AgentCore payments, with charges landing on the developer's AWS bill and no stablecoin wallet needed, which turns the AWS bill into an agent payment rail.

## 9. Claude Code 2.1.329 widens /tasks and hardens Code Mode
[Gradually](https://www.gradually.ai/en/changelogs/claude-code/)
Why it matters: the November 19 release adds scheduled tasks, loop wakeups, and forks to /tasks, caps Code Mode memory use, and surfaces remote MCP server errors in /mcp, so long unattended runs get a control panel and fewer silent failures.

## 10. Unity CLI 1.0 leaves beta for coding agents
[Unity](https://unity.com/the-unity-cli-1.0-is-here)
Why it matters: the stable CLI lets agents drive a running Editor, answer hidden dialogs, and build through the open project, with official plugins for Claude Code, Codex, Grok Build, and Antigravity, and Unity says 98 percent of its 600 million commands so far came from agents and automation.
