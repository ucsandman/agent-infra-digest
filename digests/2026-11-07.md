# Agent Infra Digest, 2026-11-07

## 1. MCPhantom: coding agents keep installing retired MCP servers with unpatched flaws
[AIP Guard](https://www.aipguard.com/blog/ai-coding-agents-installing-deprecated-mcp-servers-unpatched-flaws-mcphantom)
Why it matters: Glow Labs found agents install archived Anthropic reference MCP servers in 98 percent of tracked sessions because the names come from training data, and four high severity flaws in those servers, including a Puppeteer remote code execution bug, will never be patched after 17.3 million downloads.

## 2. GitLab 19.5 makes its MCP server GA and adds governance for external agents
[Zot News](https://zot.news/article/gitlab-19-5-puts-agentic-development-centre-devops-platform-z1ndp)
Why it matters: Claude Code, Cursor, and Codex can now reach GitLab's full tool catalog and Duo Agent Platform flows through a supported MCP server, while GitLab's governance dashboard records sessions from external agents, so the DevOps platform treats outside harnesses as governed citizens rather than shadow tools.

## 3. NVIDIA open sources Auto Ontology, a semantic layer for agents over MCP
[ExplainX](https://explainx.ai/blog/nvidia-auto-ontology-open-source-context-layer-agents-mcp-text-to-sql-2026)
Why it matters: Auto Ontology builds a business meaning layer over enterprise databases and serves it to agents through MCP, a CLI, and an API, which makes grounding an agent in real schema a shared open layer instead of a per project prompt engineering job.

## 4. Scan of 25 public MCP servers finds most skip auth basics
[DEV Community](https://dev.to/godsmasher/the-state-of-mcp-auth-november-2026-i-scanned-25-public-servers-f9b)
Why it matters: only 12 of 25 scanned public MCP servers enforce authentication, 8 are reachable with no auth at all, and only 2 advertise OAuth 2.1 discovery metadata, so the MCP ecosystem's auth spec exists mostly on paper while real servers stay open.

## 5. Cowboy raises $5M seed to launch an app store for AI agents
[Founderland](https://www.founderland.ai/articles/cowboy-raises-5m-seed-to-launch-an-app-store-for-ai-agents-mw5amq9y)
Why it matters: Cowboy opened its General Store with more than 100 agents and 10,000 data feeds on day one, betting developers will pay to distribute agents and data the way mobile developers pay to distribute apps.

## 6. Marble Cognition raises $3.75M pre-seed to turn work recordings into agent workflows
[Sesamers](https://www.sesamers.com/funding/marble-cognition-raises-3-75m-pre-seed-ai-coworkers/)
Why it matters: Marble records how employees actually work and converts it into workflows agents can run end to end, which is the training data problem for enterprise agents solved by watching the job instead of documenting it.

## 7. Perplexity launches teammates, agents that own long running business work
[Inxen News](https://www.inxen.news/news/perplexity-launches-teammates-ai-agents-that-own-long-running-business-work)
Why it matters: teammates plan projects, keep project memory across runs, and hand work to each other inside isolated environments, so Perplexity is moving from single answers to persistent agents that own outcomes, starting with Max subscribers on web.

## 8. ChatAndBuild launches Living Brain, one persistent memory across AI apps
[LaunchVideo](https://www.launchvideo.com/directory/chatandbuild)
Why it matters: Living Brain stores context outside any one model so the same knowledge written in ChatGPT can be retrieved in Claude, Cursor, or Codex, and it claims 92.2 percent accuracy on the LoCoMo benchmark with a third of the context tokens of a full conversation baseline.

## 9. CogniCore gives Claude Code and Codex a shared memory that survives sessions
[DEV Community](https://dev.to/kaushalt2004/claude-code-forgets-everything-when-you-close-it-heres-how-i-made-it-remember-and-share-it-with-30e0)
Why it matters: the open source tool saves a short structured handoff after each turn through Claude Code hooks and injects a roughly 450 token brief next session, using 53K to 60K new tokens against 147K to 216K for the leading memory plugin in its own benchmark, which is the LegCli handoff problem attacked at the hook layer.

## 10. How to give Claude Code long term memory, in four layers
[Medium](https://medium.com/@alfredodevelop/how-to-give-claude-code-long-term-memory-2026-bc5c9adef523)
Why it matters: stable rules in CLAUDE.md, a handoff note at session end, an MCP memory server for decisions, and re-injection after compaction each cover what the previous layer loses, which is a practical map of exactly where session handoff products like LegCli fit.
