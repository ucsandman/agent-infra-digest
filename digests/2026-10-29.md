# Agent Infra Digest, 2026-10-29

## 1. GitHub Copilot Fusion goes generally available, routing coding tasks across models
[VentureBeat](https://venturebeat.com/orchestration/github-copilot-fusion-mixes-models-to-achieve-near-opus-5-5-coding-performance-at-half-the-per-task-cost)
Why it matters: Fusion Max scored within two points of Claude Code with Opus 5.5 Max at about half the per-task API cost, which turns model selection from a developer decision into a platform setting and puts task-level cost at the center of coding agent pricing.

## 2. Microsoft opens the Copilot harness to developers through Foundry
[Microsoft Blog](https://blogs.microsoft.com/blog/2026/10/28/introducing-the-microsoft-copilot-harness-unlocking-the-potential-of-truly-multi-model-agentic-work/)
Why it matters: the orchestration layer behind Copilot Code, Copilot Studio, and VS Code is now a reusable runtime with MCP, agent skills, and 20 plus frontier models, so teams no longer need to build and maintain their own agent loop, sandbox, and governance.

## 3. GitHub recasts Copilot as an agentic software delivery system with Projects
[Unite.AI](https://www.unite.ai/github-makes-copilot-fusion-generally-available-at-universe-2026/)
Why it matters: Copilot Projects runs agent work across multiple repositories in parallel managed sessions, and session continuity carries one cloud agent session across the app, VS Code, CLI, and web, which is exactly the cross-surface handoff problem LegCli is built around.

## 4. Android Studio Rabbit 2 goes stable with Bring Your Own Agent for 40 plus coding agents
[Zot](https://zot.news/article/google-opens-android-studio-third-party-coding-agents-such-zoamo)
Why it matters: Claude Code, Codex, and Antigravity now run inside Android Studio over the open Agent Client Protocol with access to the emulator, profilers, and crash reports, so the IDE becomes a neutral host for agents instead of a single-vendor assistant.

## 5. ServiceNow's ChatGPT MCP plugin goes live, with Codex and security work dated for 2027
[AI Weekly](https://aiweekly.co/alerts/servicenow-and-openai-deepen-pact-with-live-chatgpt-workflow-plugin-and-codex)
Why it matters: governed ChatGPT access to existing ServiceNow workflows, enforced by the customer's own business rules and permissions, is the enterprise pattern for agents that act inside systems of record rather than beside them.

## 6. Cognitum One unveils MetaHarness, an open source factory for branded agent harnesses
[Morningstar](https://www.morningstar.com/news/accesswire/1242525msn/cognitum-one-unveils-metaharness-the-open-source-factory-for-branded-governed-ai-agent-harnesses-in-conjunction-with-github-universe-2026)
Why it matters: generating a team-owned harness with its own CLI, MCP server, scoped memory, governance policy, and witness-signed releases treats the harness, not the model, as the durable asset, and it ranked number two on the new OpenEnv Arena benchmark.

## 7. MiniMax open sources MCode Stack, the agent skills its coding team uses daily
[MarkTechPost](https://www.marktechpost.com/2026/10/28/minimax-open-sources-mcode-stack-agent-skills/)
Why it matters: 17 MIT-licensed SKILL.md skills and checklists covering subagent splits, context budgets, code review, and long-running commands show harness engineering habits becoming portable, installable artifacts that work in MiniMax Code and Claude Code alike.

## 8. OrcaRouter launches Orca Connect, turning any local GPU into a globally accessible AI API
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261028ph82150/orcarouter-launches-orca-connect-turning-any-local-gpu-into-a-free-globally-accessible-ai-api)
Why it matters: outbound-only tunnels that expose Ollama, vLLM, and llama.cpp models as OpenAI-compatible APIs for Claude Code, Codex, and other agents blur the line between local and cloud inference, which matters for anyone running agents on their own hardware.

## 9. A planted AGENTS.md file got Codex to run malware in over 90 percent of lab tests
[DEV Community](https://dev.to/gabrielanhaia/a-web-page-dropped-agentsmd-in-downloads-codex-obeyed-it-in-90-of-tests-530o)
Why it matters: the Forever Security finding shows instruction files are an attack surface no vendor can patch alone, since the agent obeyed a file dropped into Downloads, so harnesses need provenance checks on every file they treat as instructions.

## 10. Stockpress launches an MCP server for digital asset management
[WCIA](https://www.wcia.com/business/press-releases/cision/20261028FL82295/stockpress-launches-mcp-connecting-content-with-people-platforms-and-ai/)
Why it matters: letting ChatGPT or Claude search, review, and organize brand assets through MCP is another sign the protocol is spreading from developer tools into the marketing and creative teams that actually hold the content.
