# Agent Infra Digest, 2026-10-28

## 1. Oracle brings ChatGPT and Codex into its enterprise apps, plus Google TPUs to OCI
[Silicon Report](https://www.siliconreport.com/oracle-to-offer-google-tpus-on-its-cloud-infrastructure)
Why it matters: ChatGPT and Codex inside Oracle's business software puts agents where enterprise data already lives, while Google TPUs on a rival cloud in 2027 signals that agent compute is becoming multi-architecture, not single-vendor.

## 2. Akamai launches Inference and an Agent Sandbox in beta
[AI Affairs](https://www.aiaffairs.com/technology/akamai-inference-agent-sandbox-launch/)
Why it matters: 12 open-weight models behind OpenAI-compatible APIs, paired with WebAssembly isolation for agent-written code, gives teams a bounded place to run agent code at the edge instead of trusting it on shared infrastructure.

## 3. Agentic AI Foundation adds four projects at AGNTCon, reaching ten in its first year
[Pivot News](https://pivotnews.ai/five/agentic-ai-foundation-adds-four-projects-as-mcp-work-turns)
Why it matters: Alibaba's OpenSandbox, OpenAI's Open Responses, Anthropic's Agent Skills, and Hugging Face's OpenEnv landing in one neutral home is the clearest sign yet that agent standards are consolidating, even as questions about vendor neutrality persist.

## 4. Infisical raises a $40M Series B at a $600M valuation to secure agent access
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261027ny82296/infisical-raises-40-million-at-600-million-valuation-to-secure-the-ai-agent-economy)
Why it matters: led by Elad Gil, the round backs Agent Vault, a proxy that lets agents use APIs without ever holding credentials, which is the security pattern enterprises will demand before agents touch production systems.

## 5. Hyphenate raises $45M for finance-focused AI agents
[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/hyphenate-raises-45-million-dollars-finance-focused-ai-agents/)

## 6. DecisionLayer launches an MCP endpoint and Agentic Arbitration Rules
[WCIA](https://www.wcia.com/business/press-releases/ein-presswire/952415991/decisionlayer-launches-mcp-endpoint-and-agentic-arbitration-rules-bringing-dispute-resolution-to-ai-agents/)

## 7. Refersion launches an MCP server for affiliate program management
[EIN Presswire](https://www.einpresswire.com/article/952639845/refersion-launches-mcp-server-bringing-affiliate-program-management-into-chatgpt-claude-and-other-ai-assistants)

## 8. CloudCasa adds an MCP server for disaster recovery and data protection
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/27/3388960/0/en/cloudcasa-expands-disaster-recovery-integrations-with-enterprise-storage-vendors-and-introduces-a-model-context-protocol-server-for-ai-tools.html)

## 9. Anthropic experiment: experts followed their Claude Code agent's lean 86% of the time

## 10. Xcode 27 ships an MCP server for outside coding agents
[Medium](https://medium.com/macoclock/xcode-27-is-secretly-the-best-mcp-server-on-your-mac-plug-in-claude-code-codex-or-cursor-67569922e8a5)
