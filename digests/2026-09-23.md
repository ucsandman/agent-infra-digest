# Agent Infra Digest, 2026-09-23

## 1. Anthropic launches Claude Opus 5.5: Fable-class performance, 40% cheaper to run
[MacRumors](https://www.macrumors.com/2026/09/22/anthropic-claude-opus-5-5/)
Why it matters: Fable-5.1-level output at Opus pricing, with cache reads down to $0.20 per million tokens and 30%+ faster output, directly resets the cost math for long-horizon coding agent sessions and raises the bar for every competing agent model.

## 2. Zoho ships its own Zia LLM, 25+ pre-built agents, and an MCP server
[Gadgets360](https://turbo.gadgets360.com/en/ai/zoho-zia-llm-launch-ai-model-pre-built-ai-agents-marketplace-mcp-server-8895167?utm_source=website&utm_medium=content&utm_campaign=gadgets360turbo)
Why it matters: A SaaS giant now ships its own foundation model plus a pre-built agent catalog and an MCP server so third-party agents can reach Zoho's data, which shows the "MCP server as distribution" playbook is reaching enterprise suites, not just developer tools.

## 3. DigitalOcean Managed Agents enters public preview
[Morningstar](https://www.morningstar.com/news/business-wire/20260922295615/digitalocean-launches-managed-agents-bringing-agent-execution-tool-access-and-inference-together-on-one-cloud)
Why it matters: Each agent gets an isolated harness runtime, governed access to 16,000+ tools via Action Gateway, and serverless inference across 75+ models on one meter, which is the cloud-provider answer to "just run my Claude Code/Codex/LangGraph sessions for me."

## 4. Meridian launches a free MCP connector that puts Claude and ChatGPT inside Xero
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/22/3366711/0/en/meridian-launches-a-free-mcp-connector-that-lets-claude-and-chatgpt-work-inside-xero.html)
Why it matters: Agents can now run reports, inspect transactions, and create invoices in Xero with per-company read/write scopes, so the MCP connector pattern keeps spreading into regulated back-office systems where scoped, audited agent action is the product.

## 5. Aurora Mobile's GPTBots.ai adds Jev, a dedicated "decision model" layer
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/22/3366129/0/en/aurora-mobile-s-gptbots-ai-integrates-jev-two-layers-of-ai-one-enterprise-platform.html)
Why it matters: Jev returns structured yes/no/score decisions with calibrated confidence instead of generated text, so agent runtimes are splitting reasoning from judging, and the judging layer is becoming a standalone infra product with its own benchmarks.

## 6. AWS's open-source Strands harness cuts token use 28% via context management
[The Outpost](https://theoutpost.ai/news-story/aws-launches-open-source-ai-agent-framework-that-slashes-token-consumption-by-28-31146/)
Why it matters: Automatic prompt caching, truncation of long tool results, and context compaction at 85% capacity cut agent spend without model changes, which makes context hygiene a harness-level feature rather than something every agent team hand-builds.

## 7. Google brings MCP to the UN Data Commons and opens Google Home early access
[The AI Insider](https://theaiinsider.tech/2026/09/18/google-expands-ai-agent-access-with-mcp-support-for-un-data-commons-and-google-home/)
Why it matters: Agents can now query authoritative UN statistics through MCP and control Nest and Matter devices via an early-access Google Home MCP server, which keeps pushing MCP into both public data infrastructure and physical-world actuation.
