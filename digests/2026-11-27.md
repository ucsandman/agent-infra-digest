# Agent Infra Digest, 2026-11-27

## 1. Microsoft pulls its Agent Framework repo offline after poisoned PyPI releases stole credentials
[Microsoft Agent Framework Blog](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-repository-update/)
Why it matters: versions 1.26.1 and 1.26.2 of the official agent-framework package were uploaded without authorization on November 17 carrying a credential stealer, so the framework's own repo stays down until Microsoft can confirm it is safe, and anyone who installed unpinned that day must rotate every secret the environment could see.

## 2. Pydantic launches Pax, a plugin-first terminal coding agent, with the AI Harness beta
[Pydantic](https://pydantic.dev/articles/pax-harness-beta)
Why it matters: Pax treats the coding agent, sandboxes, MCP, and observability as swappable plugins, runs any model including ChatGPT and Copilot subscriptions, and can import Claude Code and Codex sessions, so the harness layer under coding agents is now a product in its own right with a 1.0 planned in about a month.

## 3. OpenClaw 2026.11.10 adds browser takeover, cited research, and linked knowledge
[Bisque](https://bisque.today/p/openclaw/openclaw-2026-11-7-to-2026-11-10)
Why it matters: you can now grab the agent's browser from the Control UI to solve a captcha or finish a login mid-run, send corrections while a tool is still executing, and run Deep Research over web and local documents, so the open-source agent harness keeps closing the supervision gap with the commercial CLIs.

## 4. Hub tops Product Hunt as an open-source dispatcher for 100 Claude Code and Codex sessions
[Product Hunt](https://www.producthunt.com/products/hub-20)
Why it matters: the Apache-2.0, self-hosted coordinator from Icons8 takes plain-language goals in a browser or Telegram, farms work out to parallel agent sessions in isolated git worktrees, and surfaces only decisions, so supervising a fleet of coding agents is becoming a packaged product, though it runs with permission prompts off and the makers call it experimental.

## 5. rust-anything crosses 10,000 GitHub stars in ten days
[GitTrend](https://gittrend.io/repo/erkamyaman/rust-anything)
Why it matters: the skill packages an agent-driven Rust rewrite as record, port, diff, and gate, with plugins for Claude Code, Codex, Cursor, Gemini CLI, and Copilot, so behavior-verified porting is the fastest-growing agent-skill pattern of the month.

## 6. Maple AI raises $5.3M seed for a private desktop agent
[The SaaS News](https://www.thesaasnews.com/news/maple-raises-5-3m-seed/)
Why it matters: led by EPIC Ventures and announced November 24, the round funds Maple Work, a desktop agent that works inside user-selected folders and apps, plus a cloud agent running in hardware-isolated enclaves, so privacy-first agent runtimes are now a funded category.

## 7. Reo.Dev raises $11.3M Series A to read buying intent from AI agents
[UXC News](https://uxc.news/p/reo-dev-lands-11-3-million-series-a-to-broaden-ai-generated-intent-signals-for-engineering-teams)
Why it matters: led by Elevation Capital, the round funds a platform that watches how autonomous agents interact with digital products and extracts purchase-intent signals, so the agent economy is already generating its own analytics layer as agents become the buyers.

## 8. Altair Semiconductor raises $100M Series A to run AI agents on edge devices
[AI Funding Tracker](https://aifundingtracker.com/ai-funding-news-november-26-2026/)
Why it matters: led by Maverick Silicon, the round funds mass production of the ALT1550 modem for smart glasses, wearables, and industrial devices, so the largest AI funding of the day went to putting agents on hardware instead of in the cloud.

## 9. CrewAI 1.15.45 hardens server auth and drops credentials on cross-origin redirects
[CrewAI Changelog](https://docs.crewai.com/edge/en/changelog)
Why it matters: the release rejects empty credentials with constant-time comparison, strips credentials on cross-origin redirects, and adds PDF output for versioned flow artifacts, which is the framework layer quietly fixing the auth gaps that multi-agent servers keep shipping with.

## 10. Fal raises $1.3B Series F at a $16B valuation for AI media infrastructure
[HeadlinesXtra](https://headlinesxtra.com/2026/11/26/fal-raises-1-3-billion-16-billion-valuation-ai-inference-november-2026/)
Why it matters: led by Bessemer Venture Partners and reported November 26, the round doubles fal's April valuation and brings its combined Series E and F total to $1.65B, so the inference layer agents call to generate images, video, and audio is now valued like core infrastructure.
