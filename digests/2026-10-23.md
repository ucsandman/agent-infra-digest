# Agent Infra Digest, 2026-10-23

## 1. Agentic AI Foundation adds four projects: Agent Skills, Open Responses, OpenEnv, OpenSandbox
[Agentic AI Foundation](https://aaif.io/news/agentic-ai-foundation-announces-four-new-projects)
Why it matters: Anthropic, OpenAI, Hugging Face, and Alibaba donated agent capabilities, multi-provider model interop, RL training envs, and sandboxing to one neutral home, so the agentic stack now has a single vendor-neutral standards body covering skills, protocols, training, and execution.

## 2. Google Cloud launches Agent Compute Engine: a hardware-isolated microVM per agent
[Crypto Nwz](https://cryptonwz.com/google-cloud-launches-agent-compute-engine-a-microvm-per-ai-agent/)
Why it matters: unveiled at AGNTCon + MCPCon, it gives each agent session its own microVM with zero credentials held, checkpoints idle agents to zero active resources, and already powers Gemini as an agent, which makes VM-grade isolation with container density the reference architecture for cloud agent execution.

## 3. VAST Data and NVIDIA launch Agent Sandbox Foundation Stack
[UpTech Media](https://uptech-media.com/vast-data-nvidia-launch-stack-for-secure-governed-ai-agent-sandboxes/)
Why it matters: pairing NVIDIA OpenShell and NemoClaw with VAST's persistent data layer keeps agent state, working data, and audit records durable while compute stays ephemeral, so agents can pause, resume, or move hosts without losing context, which is the production answer to the handoff problem.

## 4. Databricks launches Agent Memory in beta and AI Runtime for GA
[Wisevoter](https://wisevoter.com/world/us/2026/10/22/databricks-launches-agent-memory-ai-runtime)
Why it matters: Agent Memory uses the MemCurrent architecture on Lakebase so agents reuse context across queries inside governed environments, and AI Runtime adds serverless GPUs on the same data, which pushes agent memory into the enterprise data platform instead of leaving it in the harness.

## 5. Mural raises $15M Series A led by Tether for AI agent payment infrastructure
[AltcoinDaily](https://altcoindaily.co/ai-payments-startup-mural-raises-15-million-in-round-led-by-tether/)
Why it matters: Mural builds account management, identity, compliance, and spending limits so agents can transact autonomously, and Tether backing it says stablecoins are being positioned as the settlement rail for machine-driven commerce rather than human-initiated card rails.

## 6. Haystack's MCP server now works in Claude, ChatGPT, Copilot, and Slack, with write access
[PR Newswire](https://www.prnewswire.com/news-releases/haystacks-mcp-server-now-works-in-claude-chatgpt-copilot-and-slack-with-new-write-access-across-all-four-302916389.html)
Why it matters: one MCP server now delivers permission-aware intranet answers and lets employees publish pages and posts in all four assistants, which shows enterprise MCP demand shifting from read-only retrieval to agent write-back inside the tools people already use.

## 7. Traefik Labs introduces an MCP server that grounds AI agents in the gateway
[Business Wire](https://www.businesswire.com/news/home/20261022962531/en/Traefik-Labs-Introduces-the-Traefik-MCP-Server-Grounding-AI-Agents-in-the-Gateway-from-Day-0-to-Day-2)
Why it matters: the read-only server feeds agents the exact release schema, live gateway config, and Datadog/Grafana/Dash0 telemetry, so agents stop writing config that looks right but the running release rejects, which is the missing grounding layer for agents doing infrastructure changes.

## 8. Causely upgrades its MCP server so background agents run cheaper and earn trust
[Business Wire](https://www.businesswire.com/news/home/20261022339166/en/Causely-Upgrades-Its-MCP-Server-So-Background-Agents-Are-Faster-to-Deploy-Easier-to-Trust-and-Cheaper-to-Run)
Why it matters: background SRE agents at Unity and Quantum Metric get structured fault context from the MCP server with a human-checkable trail, 100% fault detection at 48% fewer tokens and 63% faster answers, which proves context pre-loaded into the MCP layer beats agents that scan the environment themselves.

## 9. iProov launches the first HAPS-compliant human-approval service for AI agents
[GenZ NewZ](https://genznewz.com/iproov-launches-human-approval-for-ai-agents-at-agntcon)
Why it matters: the hosted service gives cryptographic proof that a real human approved a specific high-risk agent action before execution, with agentgateway and Cerbos as first integrations, which turns agent governance from a policy checkbox into a verifiable primitive enterprises can buy.

## 10. Uber deploys OpenAI's ChatGPT Work agents to all 30,000 employees
[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/uber-deploys-openai-agents-to-all-30000-employees/)
Why it matters: after a 1,000-employee pilot, Uber rolled the multi-step work agent out company-wide while keeping dev teams on Codex, which is the largest single enterprise agent deployment to date and signals agents moving from pilots to standard internal tooling.
