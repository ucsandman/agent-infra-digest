# Agent Infra Digest, 2026-11-15

## 1. OpenAI launches ChatGPT Wallet so its dots agents can pay on your behalf
[Unite.AI](https://www.unite.ai/openai-launches-chatgpt-wallet-for-agent-assisted-purchases/)
Why it matters: built with American Express, Mastercard, and Visa, Wallet lets a dots agent complete purchases with network tokens while the user approves each one with a biometric check and the agent never sees the real card number, which is the first payment rail designed for agents rather than adapted from checkout forms.

## 2. Sierra ships Personal Agent Protocol 1.0 as Shopify and Meta's Muse sign on
[Unite.AI](https://www.unite.ai/sierra-releases-poppy-1-0-with-shopify-and-meta-muse-support/)
Why it matters: Poppy gives a visiting personal agent a standard way to identify itself, learn what it may do, and work through a company's APIs or agent, and with every Shopify store auto-publishing a Poppy file and Muse checking for it first, agent-to-business handshakes now have a default protocol instead of a custom integration per site.

## 3. Claude suffers two separate outages on November 13
[Vanda Team](https://vandatateam.com/blog/claude-microsoft-outages)
Why it matters: an authentication failure took down logins to claude.ai and Claude Code in the morning, then a wider incident degraded the Claude API, connectors, and Managed Agents in the afternoon, so agent work built on Claude lost both its front door and its runtime twice in one day with no root cause published for either.

## 4. Tipalti launches AP Agent with MCP links to enterprise AI tools
[Europe Says](https://www.europesays.com/3376332/)
Why it matters: the accounts-payable agent manages invoice capture through payment and reconciliation end to end, and its MCP layer lets Claude Enterprise and other tools query Tipalti's payment data in real time, so a finance workflow that moves over $100 billion a year is now reachable from an agent's tool calls.

## 5. Memro launches persistent memory for Claude Code, Cursor, and Codex
[Emergent](https://emergent.sh/news/memro-launches-persistent-memory-claude-code)
Why it matters: the Go-based, open-source system stores conversation history and project state in PostgreSQL and serves it over MCP, so coding agents stop relearning the project on every new session, which is the same cross-session memory problem LegCli works on, now with another funded open option.

## 6. Coding-agent release wave: OpenCode 2.3, Codex 0.169, Claude Code 2.1.325, llama.cpp 1.0.0
[Agent Tools Today](https://munderdiffl.in/blog/agent-tools-today-2026-11-14/)
Why it matters: OpenCode made background subagents the default, Codex added side-chat tabs and stricter handling of untrusted folders, Claude Code tightened sandboxed Bash permissions, and llama.cpp hit 1.0.0 on the same day, so the whole harness layer moved toward longer, less supervised runs in one coordinated step.

## 7. LetThemBuild launches a multi-model AI coding platform
[Emergent](https://emergent.sh/news/letthembuild-launches-multi-model-ai-coding)
Why it matters: the platform runs Claude, Codex, Gemini, Grok, and OpenRouter models in parallel on the same query and compares outputs in real time, so a coding agent's single-model failure mode becomes a routing decision, with fallback and consensus built into the interface.

## 8. Sherweb launches an MCP server for its managed service provider network
[WiseVoter](https://wisevoter.com/world/2026/11/13/sherweb-mcp-server-ai-assistants-msp-data)
Why it matters: more than 7,500 managed service providers can now have AI assistants pull subscription, pricing, usage, and billing data through MCP into Copilot Studio, GitHub Copilot, Cursor, and Claude, which extends the protocol from developer tools into the channel that sells software to small business.
