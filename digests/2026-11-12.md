# Agent Infra Digest, 2026-11-12

## 1. Anthropic turns Claude into an office suite with Sheets, Whiteboards, and interactive connectors
[OpenTools](https://opentools.ai/news/anthropic-claude-meetings-sheets-whiteboards-office-tools)
Why it matters: Claude Sheets and Whiteboards ship in beta on paid plans, Claude Data goes generally available, and interactive connectors let Adobe, Atlassian, Box, and Notion open as full apps inside Claude, so the agent is becoming the workspace, not a chat beside it.

## 2. Cursor Projects goes multiplayer, letting teammates' agents coordinate
[Cursor](https://cursor.com/blog/projects-multiplayer)
Why it matters: shared context, memory, and a task board now span a whole team, and coordinators for different teammates can share plans, flag conflicts, and unblock each other, which is the first mainstream multi-agent system built for a team rather than one person.

## 3. Google opens Agent Gateway preview for EKS, AKS, and OpenShift
[AI Weekly](https://aiweekly.co/alerts/google-opens-agent-gateway-preview-for-eks-aks-openshift)
Why it matters: the cross-cloud gateway gives each agent a verifiable identity in Agent Registry and routes LLM, MCP, and A2A traffic through local proxies enforcing Model Armor policies, extending Google's agent governance to Kubernetes clusters it does not run.

## 4. Graphon Labs raises $35M Series A to build persistent memory for AI agents
[Business Wire](https://www.businesswire.com/news/home/20261110959095/en/Graphon-Labs-Raises-%2435M-Series-A-to-Accelerate-AGI-with-Persistent-Intelligence)
Why it matters: its Persistent Intelligence layer builds a schema-free knowledge graph over enterprise data of every modality and reports top scores on LoCoMo, ConvoMem, and ATM-Bench, betting that long-term agent memory is a pre-model infrastructure layer, not a bigger context window.

## 5. WhiteMatter raises $20M Series A to govern enterprise agents with Guardian agents
[PR Newswire](https://www.prnewswire.com/news-releases/whitematter-raises-20m-series-a-to-close-the-growing-gap-between-ai-autonomy-and-enterprise-governance-302934477.html)
Why it matters: the formerly QuilrAI platform assigns a dedicated Guardian agent to enforce policy on every action of every enterprise agent, claiming 2.25 million agents under management, so governance is scaling one guard per agent rather than one dashboard per fleet.

## 6. Adobe previews local MCP for Photoshop, Illustrator, Premiere Pro, and After Effects
[iEnvi](https://ienvi.com.au/adobe-previews-local-mcp-integration-at-max-2026-letting-external-ai-a-f54f878c/)
Why it matters: announced at Adobe MAX 2026 on November 10, a local MCP server lets Claude, ChatGPT, and coding agents edit native project files non-destructively, with a private beta planned for early 2027, which puts creative apps on the same agent-tooling path as developer tools.

## 7. Codevisor adds multi-machine child agents and external MCP integration
[Undercode News](https://undercodenews.com/codevisor-just-updated-multi-machine-ai-agents-external-mcp-integration-and-a-major-bots-experience-overhaul-video/)
Why it matters: version 0.1.113-alpha.2638 lets child agents run on other machines and serves Codevisor's tools to outside MCP clients, so distributed agent work and cross-harness tool sharing arrive in one alpha, even if production readiness is unproven.

## 8. Home Assistant MCP puts agents in charge of the smart home as agent-skills repos top GitHub trending
[DEV Community](https://dev.to/max_quimby/agents-still-cant-talk-to-each-other-550g)
Why it matters: ha-mcp lets Claude and ChatGPT configure and automate a Home Assistant home, while Anthropic's skills repo sits at 193K stars and Addy Osmani's agent-skills at 115K, showing MCP has escaped developer tools into the home while the agent-to-agent layer still has no shared protocol.

## 9. Firmly raises $15M Series A to sell through AI shopping agents
[GeekWire](https://www.geekwire.com/2026/jpmorgan-and-mastercard-back-seattle-startup-firmlys-bet-on-ai-shopping-agents/)
Why it matters: led by Squarepoint Capital with J.P. Morgan Payments and Mastercard participating, Firmly connects retailers to AI shopping assistants without a per-channel integration, and it also launched Ask Agent for retailers' own sites, so agentic commerce is getting its plumbing funded by the payment networks themselves.

## 10. Ancep raises $8.5M led by Creandum for broker AI agents
[Sesamers](https://www.sesamers.com/funding/ancep-raises-8-5m-ai-insurance-placement-agents/)
Why it matters: the London insurtech's agents take the administrative work out of placing commercial insurance, with Kleiner Perkins and Vicus Ventures joining, marking the fifth broker-automation round since October and a clear vertical-agent funding pattern.
