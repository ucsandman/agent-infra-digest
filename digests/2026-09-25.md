# Agent Infra Digest, 2026-09-25

## 1. ACM Queue publishes CAFE(S), a five-dimension framework for coding agent context quality
[The Evening Leader](https://business.theeveningleader.com/theeveningleader/article/bizwire-2026-9-24-acm-queue-publishes-cafes-a-framework-for-improving-ai-coding-agent-effectiveness)
Why it matters: Researchers from Atlassian's DX, Capital One, GitHub, and Google formalize context quality into five diagnosable dimensions, giving harness builders a shared vocabulary for why agent sessions degrade even when the model is fine.

## 2. Alibaba unveils AgentCore enterprise platform and an "agentic cloud" roadmap at Apsara
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)
Why it matters: Agent Native Cloud plus Agent Context, which claims up to 67% token cuts in knowledge-intensive work, moves Alibaba from selling raw models to a managed agent platform with lifecycle management and security controls bundled in.

## 3. OX Security scans 15,465 MCP servers and finds connections to China, Russia, home networks, and abandoned domains
[PR Newswire](https://www.prnewswire.com/news-releases/new-research-mcp-servers-connect-ai-agents-to-china-russia-home-networks-and-abandoned-domains-302888066.html)
Why it matters: 15.6% of unique hostnames resolved outside the US, including home networks reached through consumer tunneling services, which proves the MCP tool layer now sits outside the security perimeter enterprises spent a decade building.

## 4. LiveKit acquires Loophole Labs to push agent startup times under three seconds
[Quebec News Tribune](https://lifestyle.quebecnewstribune.com/story/345744/livekit-acquires-loophole-labs-to-expand-its-ai-agent-infrastructure/)
Why it matters: Sub-three-second agent starts with scale-to-zero virtualization removes the idle-agent cost problem, setting the elasticity bar any agent runtime will be judged against.

## 5. Island raises $400M at $6.4B to secure enterprises as AI agents scale
[Reuters](https://www.reuters.com/technology/ai-startup-island-valued-64-billion-latest-funding-round-2026-09-24/)
Why it matters: A Series F at that valuation explicitly ties enterprise security spend to agents scaling inside companies, so agent safety tooling keeps attracting the biggest checks in the stack.

## 6. UserTesting ships two MCP servers to recruit participants and validate AI ideas inside ChatGPT and Claude
[Business Wire](https://www.businesswire.com/news/home/20260924298422/en/UserTesting-Brings-Human-Insight-Directly-into-AI-Workflows-with-New-MCP-Servers)
Why it matters: Human feedback loops entering the agent workflow via MCP means agents can close the loop from idea to customer validation without leaving the session, a new tool category on the protocol.

## 7. Ando exits stealth with an agent-native team chat where agents get real identities and inboxes, plus a $20M raise
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/today)
Why it matters: Giving agents first-class membership in team conversations instead of bolting them onto Slack forces the permission, audit, and identity questions that governance layers will have to answer first.

## 8. Darktrace launches Signal Labs after finding agentic coding assistants can be steered via conversation-history tampering
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/24/3368413/0/en/darktrace-launches-signal-labs-to-research-emerging-risks-of-enterprise-ai-agents.html)
Why it matters: Attackers modifying conversation history to compromise organizations shows the agent's memory surface itself is an attack vector, which makes tamper-evident handoff ledgers a security requirement rather than a nicety.

## 9. Brain launches a persistent company memory shared by people and AI agents, with per-person access controls
[AddOn News](https://addonnews.com/brain-launches-the-company-memory-that-makes-every-ai-in-the-business-worth-using/389928/)
Why it matters: A single memory that gets more useful as the business uses it, with different visibility for each person and agent, is the enterprise-grade version of the session handoff problem LegCli solves at the individual level.

## 10. TechTarget: persistent AI memory is becoming another enterprise data layer CIOs must govern
[TechTarget](https://www.techtarget.com/it-strategy/news/366650847/Persistent-AI-memory-adds-another-layer-to-enterprise-data)
Why it matters: With Writer, AWS AgentCore Memory, Couchbase, and Google all shipping persistent memory, retained agent context is now distributed infrastructure, and the open question is what happens when an agent acts on a stale memory.
