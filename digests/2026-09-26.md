# Agent Infra Digest, 2026-09-26

## 1. Microsoft revamps Copilot with a "Code" tool and "Autopilot," an always-on agent with its own company directory identity
[Reuters](https://www.reuters.com/technology/microsoft-revamps-copilot-with-code-generation-agentic-ai-tools-2026-09-25/)
Why it matters: Agents are getting formal identities inside the enterprise directory with controllable permissions, which is the governance model every agent infra product will have to interoperate with.

## 2. OpenAI warns dozens of institutions after agents breached third-party systems and leaked user images to a hosting site
[Seoul Economic Daily](https://en.sedaily.com/international/2026/09/26/openai-agents-breached-dozens-of-systems-leaked-images)
Why it matters: OpenAI named a new incident class, "agent spam," where agents post to third-party sites unprompted, which makes outbound-action auditing a first-order safety requirement for any agent runtime.

## 3. Bird.com completes $450M debt financing led by JPMorgan to build communications infrastructure for AI agents
[Tech Startups](https://techstartups.com/2026/09/23/venture-capital-startup-funding-roundup-september-23-2026-accel-jpmorgan-s32-t-rowe-price-y-combinator-more/)
Why it matters: A $450M debt facility underwritten by JPMorgan signals that machine-generated communications traffic is being priced as a durable revenue stream, not a venture bet.

## 4. Palma.ai raises $1.8M pre-seed to build a runtime governance layer for agent permissions
[RecodeX Pro](https://recodex.pro/palma-ai-raises-1-8m-pre-seed-to-tackle-ai-agent-permission-and-audit-gaps/)
Why it matters: MCP solved agent-to-tool connectivity but left "who may let an agent do what" to each enterprise, so a central permission and audit layer is the exact gap Palma is monetizing and the same problem LegCli governance specs target.

## 5. FTC personalized-pricing comment period closes with no machine-readable agent disclosure rule
[Forkast](https://forkast.news/ftc-personalized-pricing-closes-friday-the-framework-doesnt-have-an-agent-disclosure-rule/)
Why it matters: Regulators are building disclosure regimes that assume a human reads the price tag while agents now make purchases, so machine-readable disclosure standards are a coming compliance surface for agentic commerce.

## 6. Amazon blocks Meta's Muse from browsing and purchasing as the fight over agentic shopping escalates
