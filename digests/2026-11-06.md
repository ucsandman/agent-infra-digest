# Agent Infra Digest, 2026-11-06

## 1. NVIDIA paper: agents keep accuracy with 16K context via handoff notes
[Crypto Briefing](https://cryptobriefing.com/nvidia-study-ai-agents-short-contexts/)
Why it matters: compacting history into short handoff notes matched full-history accuracy on SWE-bench Verified while cutting peak context from 130K-200K tokens to 15K-37K, which says the context problem is a handoff design problem, not a window size problem.
