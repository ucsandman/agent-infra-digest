# Agent Infra Digest, 2026-11-19

## 1. Microsoft sells enterprises an MCP Firewall at Ignite
[Anchor Terminal](https://www.anchorterminal.com/blog/closing-the-doors-on-mcp)
Why it matters: Entra's MCP Firewall in preview lets admins control which MCP servers, tools, and transports agents can reach, while Agent 365 hunts shadow servers and Intune cuts off devices running unapproved agents, so enterprise MCP governance is becoming a Microsoft product line, not a policy doc.

## 2. Copilot Studio agents get their own accounts, and shared memory
[Windows Forum](https://windowsforum.com/news/microsoft-copilot-studio-ignite-2026-agent-accounts-shared-memory-risks-and-governance.453078/)
Why it matters: dedicated agent accounts with managed credentials reach public preview in December, and account-based agents share memory across everyone they work with, so persistent agents in Copilot Studio are now first-class participants with a real cross-contamination caveat IT has to plan around.

## 3. HYPR launches AgentPass to give every AI agent a human supervisor
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/11/18/3405704/0/en/hypr-launches-agentpass-to-assign-every-ai-agent-to-an-accountable-human.html)
Why it matters: AgentPass binds each agent to a named human, checks identity and policy before actions run, routes high-risk actions to passkey-signed approval, and covers coding agents on developer laptops that a network gateway never sees, which is agent identity treated as an endpoint problem, not just a cloud one.

## 4. Model ML raises $250M Series B at a $1.5B valuation for personal finance agents
[General Atlantic](https://www.generalatlantic.com/media-article/model-ml-raises-250-million-at-1-5-billion-valuation-18-months-after-launching-from-stealth/)
Why it matters: co-led by General Atlantic and QED Investors, the round takes total funding to $350M on reported 12x ARR growth, and the agents run inside banks' own systems on their own data, so the personal-agent model is winning in the most regulated vertical first.

## 5. Disseqt raises $8M to build the assurance layer for enterprise agents
[Unite.AI](https://www.unite.ai/disseqt-ai-raises-8m-to-expand-ai-assurance-internationally/)
Why it matters: led by Gresham House Ventures with angels from OpenAI, Palo Alto Networks, Salesforce, and Meta, the Dublin startup tests agents before launch, enforces policy live, and keeps audit evidence, which is governance as a pre-deployment gate rather than a post-incident report.

## 6. Humyn Labs raises $47M Series A to prepare physical AI for the real world
[YourStory](https://yourstory.com/2026/11/physical-ai-startup-humyn-labs-raises-47-million-series-a)
Why it matters: led by Accel with $26M equity plus $21M venture debt, the Bengaluru startup builds deployment-readiness infrastructure for robots in Brazil, South Korea, and India, so physical AI funding is now flowing to the testing and deployment layer, not just the models.

## 7. Codex CLI 0.170.0 adds realtime voice calls in the terminal
[Releasebot](https://releasebot.io/updates/openai/codex)
Why it matters: the November 18 release negotiates voice calls over WebRTC in the TUI, adds experimental support for same-named MCP servers across environments, and fixes MCP OAuth credential races, so the coding agent is gaining a voice interface and steadier multi-environment tool wiring in the same patch.

## 8. Astra Security connects autonomous pentesting to Claude and Copilot over MCP
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/11/18/3406062/0/en/astra-security-connects-autonomous-pentesting-to-claude-code-and-github-copilot-through-new-mcp-server.html)
Why it matters: Astra MCP pipes exploit-validated findings and codebase-specific fix prompts into Claude Code, Copilot, Cursor, and ChatGPT with permission-scoped access, so security findings now land in the editor as fixable work instead of a separate report.

## 9. Digital.ai Release 26.3 brings agents into governed enterprise delivery
[Business Wire](https://www.businesswire.com/news/home/20261118284669/en/Digital.ai-Release-26.3-Brings-AI-Agents-into-Governed-Enterprise-Delivery)
Why it matters: the Release MCP Server lets coding agents start, analyze, and optimize releases from Cursor, Claude Code, or Codex without leaving their tools, which puts agents inside the release pipeline as governed actors rather than outside it as observers.

## 10. Code Effects v7 adds an embeddable MCP server for business rules
[TechNews180](https://technews180.com/artificial-intelligence/code-effects-version-7-secure-ai-agents-net-rules-engine/)
Why it matters: the embeddable MCP server lets external agents read rules, tests, and evaluation history while deterministic execution and human approval stay mandatory for publishing, so rule engines are opening to agents on a read-mostly, human-gated terms.
