# Agent Infra Digest, 2026-10-09

## 1. Google Cloud launches Gemini agent for work, with "coworker agents" that get their own email
[Reuters](https://www.reuters.com/business/google-cloud-introduces-gemini-agent-work-ai-race-heats-up-2026-10-08/)
Why it matters: A generalist agent living inside Workspace, Microsoft 365, and Slack that spins up persistent coworker agents with their own email and scoped access is Google betting that durable agent identity, not chat windows, is the enterprise pattern.

## 2. Apollo GraphQL ships GraphOS Agent Services for governed agent access to enterprise APIs
[Wcia](https://www.wcia.com/business/press-releases/cision/20261007SF65393/apollo-graphql-introduces-graphos-agent-services-giving-ai-agents-governed-access-to-enterprise-apis-and-systems/)
Why it matters: With Intuit, American Airlines, and Block piloting, Apollo's move says the agent tool-access problem is being solved by explicit domain models with ACLs baked in, not by giving agents raw API keys and hoping the model behaves.

## 3. CoreWeave Forge launches to unify the full model-and-agent development loop
[StorageNewsletter](https://www.storagenewsletter.com/2026/10/08/coreweave-fully-connected-2026-coreweave-forge-launches-turning-the-ai-loop-production-run-into-a-better-model-and-agent/)
Why it matters: Training, inference, evaluation, and agent development in one connected environment where production traces feed the next training run is exactly the closed loop most teams hand-roll today, and MasterClass and Canva are already building on it.

## 4. Commvault will now back up agent configurations and accumulated AI context on laptops
[StorageNewsletter](https://www.storagenewsletter.com/2026/10/08/commvault-protects-and-recovers-agent-configurations-and-ai-data-that-employees-cant-afford-to-lose-on-their-laptops/)
Why it matters: When backup software treats your agent's configs, prompt libraries, and context as data worth protecting and recovering, agent working state has crossed from disposable scratch into durable institutional knowledge.

## 5. Qt ships a QML Live Preview MCP tool so agents can watch their own UI edits hot-reload
[Qt](https://www.qt.io/blog/introducing-the-qml-live-preview-mcp-tool-for-agentic-development-of-embedded-devices)
Why it matters: The agent edits embedded UI files and sees the running app update without a rebuild, which closes the verify step of the coding-agent loop for an entire device class and makes the agent's work transparent to the human watching.

## 6. Google's Developer Knowledge MCP server gives coding agents official docs on demand
[WebProNews](https://www.webpronews.com/googles-developer-knowledge-api-arms-ai-agents-with-official-docs/)
Why it matters: An official MCP server plus a CLI surfacing Firebase, Android, and Cloud docs (fresh within 24-48 hours) means coding agents can ground answers in authoritative sources instead of hallucinating API details from stale training data.

## 7. "Agents don't need memory. They need documentation" sparks the month's biggest architecture debate
[DEV](http://dev.to/danielsamfdo/your-agents-memory-is-a-lottery-the-memory-vs-documentation-war-of-2026-40lc)
