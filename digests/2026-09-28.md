# Agent Infra Digest, 2026-09-28

## 1. NVIDIA launches Open Agent Safety Platform: open-source OpenShell runtime plus Sentry watchdog on BlueField-4 DPUs
[Stockhouse (press release)](https://stockhouse.com/news/press-releases/2026/09/28/nvidia-launches-open-agent-safety-platform-to-secure-agents-from-testing-to)
Why it matters: NVIDIA is defining agent governance in hardware and runtime, a secure boundary that traces all actions and quarantines rogue agents in milliseconds, which raises the bar for every software-only session control LegCli-style products can offer.

## 2. iProov publishes HAPS, an experimental spec for verifiable human approval of AI agent actions
[TechTravelMonitor](https://techtravelmonitor.com/2026/09/28/iproov-publishes-haps-an-experimental-specification-for-verifying-human-approval-of-ai-agent-actions/)
Why it matters: The spec distinguishes having permission from proving a human approved this exact action, with biometric liveness as one proof, so approval-gating is becoming a protocol layer rather than a product feature, directly relevant to how LegCli frames its Land flow.

## 3. Microsoft Agent Framework settles into stable 1.x releases (Python 1.19.0, .NET 1.22.0, shipped September 18)
[Tech Insider](https://tech-insider.org/microsoft-agent-framework-setup-2026/)
Why it matters: Semantic Kernel and AutoGen are now one versioned production SDK, so teams building multi-agent workflows on Microsoft's stack finally have a stable target, which concentrates ecosystem energy on a single framework idiom.

## 4. Microsoft rebuilds Copilot around a coding tool and an always-on "Autopilot" agent with its own corporate identity
[Reuters](https://www.reuters.com/technology/microsoft-revamps-copilot-with-code-generation-agentic-ai-tools-2026-09-25/)
Why it matters: Autopilot gets a directory identity and user-controlled permissions like a new hire, and cost-management tooling ships alongside, so the enterprise agent conversation is now identity plus budget, not just capability.

## 5. A Claude Code agent reportedly deleted 48,000 files, then apologized
[AI Agents Directory](https://aiagentsdirectory.com/news/ai-agents-news-brief-september-27-2026)

## 7. Meta's Muse AI agent expands to Instagram profiles after a top-free-app debut
