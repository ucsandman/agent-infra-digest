# Agent Infra Digest, 2026-10-02

## 1. Earendil ships Pi 1.0 with native MCP and Codemode, plus experimental Pi Durable
[Subagentic](https://subagentic.ai/posts/pi-1-0-and-pi-durable/)
Why it matters: The minimal terminal harness gets MCP natively on Oct 1, while Pi Durable becomes a separate substrate for long-running agents, so session persistence is now a first-class product line, not a terminal hack.

## 2. St. Louis Fed launches FRED MCP Connector for AI agents
[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/st-louis-fed-adapts-fred-database-for-ai-agents/)
Why it matters: A federal statistical database now serves agents as a first-class audience with documented retrieval semantics, a sign that serious data providers are redesigning interfaces for machines, not screens.

## 3. Tuskira open-sources an AI agent runtime gateway
[Business Wire](https://www.businesswire.com/news/home/20261001311789/en/Tuskira-Launches-Open-Source-AI-Agent-Runtime-Gateway-to-Observe-Govern-and-Switch-LLMs-and-MCP-Tools-Without-Rewiring-Agents)
Why it matters: One self-hosted gateway for model routing, MCP access control, activity logging, and token spend tackles the "unmanaged agent sprawl" problem with visibility and policy, the exact governance gap enterprises cite when adopting agent fleets.

## 4. Commvault adds AI agent discovery and recovery to endpoint protection
[Compare the Cloud](https://www.comparethecloud.net/news/commvault-adds-ai-agent-discovery-and-recovery-to-its-endpoint-protection-offering)
Why it matters: Backup of locally stored agent context (prompt libraries, custom instructions, project context) becomes a security product feature, confirming that cross-session context is now considered data worth protecting and restoring.

## 5. Microsoft releases 301,000 Copilot coding-agent traces for researchers
[RuntimeWire](https://runtimewire.com/article/microsoft-opens-copilot-coding-agent-traces)
Why it matters: 9.3M model calls and 8.7M tool calls of metadata-only telemetry let infra researchers test harness assumptions against real usage without seeing private code, a rare public dataset for the agent-infra crowd.

## 6. Barclays plans Claude Code for half its developers by year end
[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/barclays-accelerates-ai-rollout-with-anthropic-claude-code/)
Why it matters: A universal bank committing most developers to an agentic coding tool by end of 2027 signals that coding agents are crossing from pilot to standard enterprise toolchain, with procurement and governance following close behind.

## 7. Restate raises $20M Series A for durable agent execution
[TechCrunch](https://techcrunch.com/2026/09/30/restate-lands-20m-as-the-need-for-durable-infrastructure-increases-with-ai-agents/)

## 10. Sigo Seguros opens an insurance MCP server and InsuranceMCP.com directory
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261001da62247/sigo-seguros-opens-its-auto-insurance-mcp-server-to-chatgpt-grok-bot-and-muse-others-are-blocking-them)
