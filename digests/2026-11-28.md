# Agent Infra Digest, 2026-11-28

## 1. NVIDIA study: letting models manage their own context nearly triples scores at tight budgets
[arXiv](https://arxiv.org/abs/2611.34147v1)
Why it matters: in NVIDIA's NOOA harness, GPT-6.1 went from 21% to 56% on a document research benchmark at a 32K budget when the model chose when and what to compact instead of the harness, so context management is becoming a model capability rather than a harness heuristic.

## 2. Cloudflare launches Search for Agents, a one-toggle search endpoint for AI agents
[Cloudflare Docs](https://developers.cloudflare.com/changelog/product-group/ai/)
Why it matters: one dashboard toggle creates an AI Search instance and serves a site's content as Markdown at /.well-known/search, so any Cloudflare site can now be found and read by agents without building a search integration, with the site owner paying per query from December 1.

## 3. OpenAI plans one shared token allowance across ChatGPT and Codex from December
[SXF Brief](https://sxf.si/brief/)
Why it matters: Plus, Pro, and Business subscribers will draw advanced ChatGPT and Codex work from a single token-based allowance, so budgeting coding-agent usage becomes a shared pool instead of two separate meters.

## 4. Microsoft Research: coding agents write much larger patches, and most of the extra is tests
[The Signal Room](https://betabriefing.ai/channels/the-signal-room/briefings/2026-11-27/)
Why it matters: across 7,660 Copilot CLI executions on 18 frontier models, 61% of agents' extra edits on SWE-bench Verified were automated tests and 13% were documentation, so agent output is changing the composition of codebases, not just their volume.

## 5. Cognition claims a 40x jump in merged PRs per engineer with its software factory playbook
[The Signal Room](https://betabriefing.ai/channels/the-signal-room/briefings/2026-11-27/)
Why it matters: Cognition's CPO reported merged pull requests up 40x while engineering headcount grew only 2.7x, so the Devin maker's internal numbers are now the loudest claim yet that agent-run development scales output per engineer, not just total output.

## 6. JetBrains ships Mellum2.1 Instruct, an Apache 2.0 coding model with 2.5B active parameters
[SXF Brief](https://sxf.si/brief/)
Why it matters: the 12B-total, 2.5B-active model favors concise tool calls and routine coding tasks over extended reasoning, so small open models keep carving out the cheap-worker slot under the big coding agents.

## 7. UX Pilot open-sources an MCP skill that makes coding agents design before they code
[The Anvil](https://betabriefing.ai/channels/the-anvil/briefings/2026-11-27/)
Why it matters: the Apache 2.0 skill forces an explicit visual design phase on a canvas, with editable screens compiled to code using the project's own design tokens, so agents stop jumping straight from a prompt to inconsistent UI.

## 8. Vercel's Board lets people and coding agents coordinate work on a shared message board
[Talking Fingers](https://talkingfingers.net/topics/building-with-agents/2026/11/)
Why it matters: the experimental Board gives Claude Code, Codex, OpenCode, Mastra, and LangChain agents a CLI and JavaScript SDK to post and read work updates alongside humans, so multi-agent coordination gets a shared surface instead of living in each agent's own session.

## 9. MCP Inspector 2.17.0 ships Events support and an SSRF guard for IPv6 and NAT64
[Dockware Labs](https://dockwarelabs.dockfinity.com/discovery)
Why it matters: the official Inspector now listens on the Events extension, SEP-3415, which the MCP site marks Final, and blocks crafted IPv6 addresses, so testing MCP servers gets both the new event stream and a network-safety fix in one release.

## 10. Google describes Cloud Agent Gateway, an identity-checked front door for LLM, MCP, and A2A traffic
[Talking Fingers](https://talkingfingers.net/topics/building-with-agents/2026/11/)
Why it matters: the gateway checks each agent's identity against Agent Registry, applies IAM policy with default-deny egress, and screens requests with Model Armor, so agent traffic to Google Cloud gets a governed entry point instead of direct API calls.
