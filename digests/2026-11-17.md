# Agent Infra Digest, 2026-11-17

## 1. SnapLogic launches MCP Discovery Hub, a registry for enterprise MCP servers
[The News Headliner](https://thenewsheadliner.com/snaplogic-launches-mcp-discovery-hub-adds-new-ai-agent-building-and-governance-capabilities/72590/)
Why it matters: the searchable catalog lets developers find existing MCP servers, copy working client configs for Claude Code, Cursor, or VS Code, and reuse them instead of building one-off integrations, so MCP discovery is becoming a governed enterprise catalog rather than a folder of JSON files.

## 2. Together AI agent evals: fixing docs, skills, and API errors lifted coding-agent completion from 75% to 97%
[explainx.ai](https://www.explainx.ai/blog/together-ai-agent-evals-97-percent-coding-agents-november-2026)
Why it matters: baseline, MCP, and skills configs were scored side by side on real platform tasks, and small documentation and error-message fixes did more than any model swap, which makes agent experience the new developer experience for any API agents will call.

## 3. OpenAI Responses API bug: approved MCP writes can replay when combined with hosted reads
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week?ref=blog.svil.dev)
Why it matters: a November 16 bug report shows an approved native MCP write sometimes executing twice when the same response continues with a hosted programmatic read, so builders relying on in-response approvals need idempotency on every MCP write or risk duplicate side effects.

## 4. Claude Code 2.1.326 patches background-session data loss and adds Code Mode to agent teams
[Gradually](https://www.gradually.ai/en/changelogs/claude-code/)
Why it matters: the November 16 release fixes resumed sessions losing turns and history after crashes, stops background sessions from firing model requests with a lost gateway, and lets Code Mode run inside agent teams, so long unattended runs get materially safer.

## 5. Google ships Gemini 4 Hydrogen, a fast model built for agentic workflows
[Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/?ref=thehype.news)
Why it matters: Hydrogen scores 51 on the Artificial Analysis Intelligence Index at $1.50/$7.50 per million tokens flat across its 1M-token window, positioning it as the cheap execution engine under Carbon in multi-model agent workflows rather than another frontier bid.

## 6. AT&T runs nearly 500 agentic workflows in production and plans to triple them in 2027
[SiliconANGLE](https://siliconangle.com/2026/11/14/att-uses-agentic-ai-to-reinvent-business-processes-from-the-ground-up/)
Why it matters: the platform handles over 1 million transactions a month and AT&T processes about 45 billion AI tokens a day, with humans removed only after accuracy hits the mid-to-high 90s, which is the clearest large-enterprise template yet for scaling agents with a graduation gate.

## 7. OpenAI Agent Builder shuts down November 30, and the export is not the workflow
[AI Agents Watch](https://aiagentswatch.com/posts/openai-agent-builder-shutdown/)
Why it matters: Agent Builder, the Evals dashboard and API, and reusable prompts all close on November 30, and the Agents SDK export does not convert the workflow graph, so teams with live canvases have 13 days to export and manually rebuild or lose the running workflow.

## 8. Hatz AI raises $24M Series A to sell AI to small business through MSPs
[ChannelVision Magazine](https://channelvisionmag.com/hatz-ai-raises-24m-in-series-a-funding/)
Why it matters: led by Nadia Partners, the round funds an AI control plane delivered only through managed service providers, with partner count tripled year over year, betting that the MSP channel, not direct sales, is how AI agents reach millions of small businesses.

## 9. Dreamteam raises $53M for an AI-native CRM with four built-in agents
[Foundra](https://www.foundra.ai/key-reads/dreamteam-53m-ai-native-crm-100-customers-three-months-replacing-salesforce-hubspot-how-to-attack-an-incumbent-first-time-founders-2026)
Why it matters: the Freshworks-alumni startup signed over 100 customers in three months with agents that research prospects, draft follow-ups, flag at-risk deals, and set up workflows, so the CRM challenger story is now an agent story, not a feature-parity story.

## 10. Masttro launches a read-only MCP server for family-office wealth data
[Business Wire](https://www.businesswire.com/news/home/20261116816594/en/Masttro-Expands-AI-Interoperability-for-Family-Offices-with-New-MCP-Server-and-Developer-Portal)
Why it matters: the server gives authorized AI apps read-only access to holdings, transactions, and ownership structures for over 400 family offices, with MCP disabled by default, which is the conservative, opt-in pattern for bringing agents into the most sensitive financial data there is.
