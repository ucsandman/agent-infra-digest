# Agent Infra Digest, 2026-11-09

## 1. Tampered Claude Code extension served from Cursor's marketplace installed an SSH backdoor
[Digital Soul Hub](https://digisoulhub.com/blog/ai-week-in-review-nov-8/)
Why it matters: versions 2.1.312 and 2.1.313 of the Anthropic.claude-code extension on Cursor's marketplace were not built by Anthropic and tried to install a persistent SSH backdoor, so the extension supply chain is now a live attack surface for coding-agent users.

## 2. Anthropic ships Claude Enterprise Security Center and makes inference hooks generally available
[AI Morning Briefing](https://news.molroo.com/en/posts/2026-11-07-0600-ai-morning-briefing)
Why it matters: real-time DLP inference hooks plus a security center for Claude Enterprise give governed agent deployments the runtime controls enterprises have been asking for, and they arrive the same week a tampered extension showed why those controls matter.

## 3. Pliant raises $80M Series C to let agents run B2B payments over MCP
[MindPattern](https://www.mindpattern.ai/s/2026-11-05-pliant-raised-80-million-to-let-claude-chatgpt-and-in-house-agents-run-b2b-payments-o)
Why it matters: Claude, ChatGPT, and in-house agents can now run payment workflows on Pliant's licensed rails through MCP with permissions and audit trails, and with over $100M in annual recurring revenue, agent-driven money movement is a funded product line, not a demo.

## 4. Palo Alto Networks in talks to buy agent security startup Clutch for $500M
[The AI Insider](https://theaiinsider.tech/2026/11/09/palo-alto-networks-in-talks-to-acquire-ai-agent-security-startup-clutch-security-for-500m/)
Why it matters: Clutch secures agents' access to company systems, and a $500M price at roughly 50 times its near-$10M ARR says the biggest security vendor now treats agent access control as a must-own layer.

## 5. GitHub Copilot lands in Xcode's coding assistant and JetBrains Air via ACP
[JavaRubberDuck](https://javarubberduck.com/ai/news-2026-11-08-dev-tools/)
Why it matters: Copilot now runs inside Xcode 27.3 beta and as an agent in JetBrains Air over the Agent Client Protocol, so the coding agent is becoming a portable service that plugs into other vendors' surfaces instead of a feature of one editor.

## 6. Apple quietly ships its own Xcode plugin into Claude Code's official marketplace
[Tayyab Ismail](https://tayyabismail.substack.com/p/apple-quietly-put-its-own-xcode-plugin)
Why it matters: Apple merged PR 6338 into Anthropic's claude-plugins-official marketplace on November 6 with no press note, letting Claude Code drive Xcode through a plugin the IDE already ships, which is platform vendors meeting agents halfway instead of waiting to be disrupted.

## 7. Kiokuko hits v1.0.68 after nine releases in five days, pushing persistent memory for coding agents
[Undercode News](https://undercodenews.com/kiokuko-just-updated-v1068-arrives-after-a-rapid-series-of-releases-pushing-ai-agent-memory-development-forward-video/)
Why it matters: Kiokuko keeps project knowledge in a SQLite store outside the context window and serves it to Codex, OpenCode, Claude Code, and Hermes over MCP, and the release cadence shows how fast the cross-session memory space is still moving.

## 8. GhostDrive Crew lets several AIs work one task through your memory, each with its own scoped token
[GhostDrive](https://www.ghostdrive.com/News/crew-your-ais-on-one-task)
Why it matters: a local gateway gives Claude Code, Codex, or any MCP client its own bearer token and scopes, and no crew member can send, pay, sign, or publish alone, which is multi-agent coordination with the permission model built in from the start.

## 9. 31C launches MCP ONE, bringing deep packet intelligence to AI agents
[Canadian Tech Letter](https://www.cantechletter.com/newswires/31c-launches-mcp-one-server-ai-agents-join-people-and-machines-as-users-of-odun-one-deep-packet-intelligence/)
Why it matters: agents can now query ODUN.ONE's network intelligence over MCP, identifying over 11,000 applications inside encrypted traffic without decryption, and the server runs on the customer's own infrastructure, so packet data never leaves their network.

## 10. Ergen launches a financial world-model MCP server tracking multi-hop risk
[TechBytes](https://blogs.techbytes.app/posts/world-model-mcp-for-finance/)
Why it matters: the server feeds agents a scored graph of relationships between companies, executives, suppliers, and regulators, so autonomous trading and risk agents can trace how distress propagates across degrees of separation instead of reading isolated balance sheets.
