# Agent Infra Digest, 2026-11-26

## 1. Google makes Workspace MCP servers GA and sets a February 2027 deadline to drop REST APIs
[Google Workspace Blog](https://workspace.google.com/blog/product-announcements/built-for-trust-and-control-new-ai-agent-protections-and-developer-tools-in-google-workspace)
Why it matters: agents must reach Gmail, Drive, Docs, Sheets, Calendar, Chat, and Tasks through Google's MCP servers or the new gwscli from February 1, 2027, so the largest productivity suite just made MCP the only sanctioned agent front door.

## 2. Anthropic launches Claude Ship to review, fix, and approve GitHub pull requests
[The Register](https://www.theregister.com/ai-and-ml/2026/11/24/claude-ship-puts-ai-at-the-helm-of-pull-request-approvals/5311883)
Why it matters: PR Steward pushes fixes for failing checks and review feedback while Claude Approvals signs off routine changes under a policy file in the repo, so the merge queue is now a place agents act with sign-off authority, not just suggestions.

## 3. Claude artifacts become installable Mac and Windows apps in beta
[Claude](https://claude.com/resources/articles/install-as-app?ref=testingcatalog.com)
Why it matters: an artifact gets its own icon and window, runs on your Claude account with your connectors, and can ask for full computer access, so agent-built tools graduate from chat panels into installed software with a permission model to match.

## 4. Cognition releases SWE-2.1, doubling its coding model's Terminal-Bench score
[Sulat](https://news.sulat.com/2026/11/25/devin-swe-2-1/)
Why it matters: the RL-trained model on Moonshot's Kimi K3 scores 50.0 on Terminal-Bench 4.1 against SWE-2's 24.2, with a Cerebras-served Lightning variant at 10x speed and a looser Cyber variant for Devin Security, but it stays Devin-only with no API or weights.

## 5. Canva makes its MCP server generally available with no waitlist
[Canva Newsroom](https://www.canva.com/newsroom/news/canva-mcp-update/)
Why it matters: any developer can now wire agents into Canva's design engine alongside new REST APIs and a CLI, and nearly 500,000 people have already signed up for Canva through MCP since October, so design is becoming an agent-callable service at consumer scale.

## 6. ZDI discloses an MCP command-injection RCE in LiteLLM with no patch coming
[CVE Threat Intelligence](https://cve.threatint.com/CVE/CVE-2026-136535)
Why it matters: CVE-2026-136535 lets an authenticated user run commands as the LiteLLM service account through MCP stdio configs, and the vendor disputes it is a vulnerability, so self-hosted LLM gateways that front agent traffic need the 1.104.0 stdio-off default rather than a fix.

## 7. AWS releases Strands Decider v2, five open decision models for agent routing
[Dataconomy](https://dataconomy.com/2026/11/25/aws-releases-open-weight-strands-decider-v2-models/)
Why it matters: the Apache 2.0 models on Gemma 4 score bounded choices like tool selection and ticket routing in one forward pass, and AWS reports 94 percent of Sonnet's task success at 44 percent of the cost, so cheap decision models are becoming the routing layer under expensive generators.

## 8. Meta launches Muse in the UK with 14 local retail and travel partners
[Meta](https://about.fb.com/news/2026/11/introducing-muse-in-the-uk-a-personal-ai-agent-you-control/amp/)
Why it matters: M&S, Sainsbury's, Ocado, Argos, easyJet, and Trainline now connect directly to Meta's personal agent, with checkout through Stripe Link and Shop Pay after user approval, so agentic commerce in the UK moves from demos to real baskets in the Christmas trading period.

## 9. MyClaw 3.0 launches always-on cloud agent teams with shared memory
[Product Hunt](https://www.producthunt.com/products/myclaw-3-0)
Why it matters: the top Product Hunt launch of November 25 sells persistent cloud teammates across OpenClaw, Claude Code, Codex, Hermes Agent, and Pi with shared memory and 50-plus model choices, so the hosted multi-agent team is now a packaged product, not a self-hosted project.

## 10. XEBO.ai raises $10.5M Series A to push agentic AI into experience management
[PR Newswire](https://www.prnewswire.com/news-releases/xeboai-raises-10-5-million-in-series-a-funding-from-emirates-growth-fund-302951035.html)
Why it matters: the Emirates Growth Fund round funds agentic AI across the Dubai-based platform's voice-of-customer analytics, so customer feedback work joins the list of enterprise functions being rebuilt around agents rather than dashboards.
