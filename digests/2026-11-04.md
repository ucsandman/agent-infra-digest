# Agent Infra Digest, 2026-11-04

## 1. Traversal raises $120M Series B at a $1B valuation for autonomous site reliability agents
[Silicon Report](https://www.siliconreport.com/traversal-raises-120-million-series-b-at-1-billion-valuation)
Why it matters: Kleiner Perkins, Redpoint, and Khosla co-led the round for agents that diagnose, remediate, and try to prevent production outages, and ninefold ARR growth plus 150,000 investigations last quarter makes SRE the best-funded proof that long-running agents can hold production responsibility.

## 2. First cross-framework MCP study finds a 22.9% tool-poisoning attack success rate
[NextVector](https://nextvector.rhasan.online/article/first-cross-framework-mcp-tool-poisoning-study-finds-23-percent-exploit-rate)
Why it matters: across 9,720 cells, 12 frameworks, and 18 models, zero frameworks offered intentional defense and 12.1% of successful attacks exfiltrated credentials, so MCP security now has a measured baseline and a case for signed manifests and hash-pinned tool definitions.

## 3. MCPhantom: coding agents keep installing deprecated MCP servers from training data
[Medium](https://medium.com/cagris-biz-stack/mcphantom-ai-coding-agents-are-installing-deprecated-mcp-servers-eeb4afb16b39)
Why it matters: in 98% of reviewed sessions the agent pulled package names from memory instead of checking what is current, and the deprecated servers have 17.3M npm downloads since July 2025, so harness setup needs a deprecation check before any install step.

## 4. Snowflake puts CoCo and CoWork on the same governed footing for scheduled work
[Subagentic](https://subagentic.ai/posts/snowflake-coco-cowork-expedition/)
Why it matters: cloud-hosted CoCo sessions that keep running after the engineer logs off, with production changes still left to a person, plus CoCo Automations and an Async Agent API now generally available, shows governed async agents moving from demo to enterprise default.

## 5. Code Mode: the case for giving agents one exec tool instead of a tool catalog
[Liviu Tudor](https://liviutudor.com/2026/11/03/of-ai-agents-code-mode-and-the-one-tool-to-rule-them-all/)
Why it matters: compiling tool schemas into TypeScript declarations and letting the model script chained calls in a sandbox cut one agent's spend 15% while lifting its Terminal-Bench score 3.5 points, which reframes context efficiency as a harness design choice, not a model property.

## 6. Salesforce doubles Agentforce memory recall with an update-as-correction policy
[Salesforce](https://www.salesforce.com/blog/agentforce-memory-update/?bc=OTH)
Why it matters: treating new customer information as a correction to existing memory rather than an additional fact lifted recall 1.8x for stated facts and 2.2x for changed facts, a policy lesson any session-memory design can steal without new architecture.

## 7. ToolSpace mines real MCP traces and drops frontier models up to 38.2 points
[AI Weekly](https://aiweekly.co/alerts/toolspace-mines-mcp-traces-drops-frontier-models-382-points)
Why it matters: building benchmarks from 77,760 tool-call patterns over 2,042 real tools exposed how much standard tool-use benchmarks flatter frontier models, and its 744B variant beating GPT 5.6 Sol on long-horizon tasks says training on real traces, not invented ones, is the next lever.

## 8. Guava raises a $12.5M seed for a voice agent developer platform
[MarketMinute](https://wkow.marketminute.com/article/bizwire-2026-11-3-guava-lands-125-million-to-tackle-voice-ais-real-world-growing-pains)
Why it matters: built on a decade of Gridspace call-center model work with tens of thousands of regulated calls per day already, Guava bets voice agents win on real-world reliability, not demo fluency, and Acrew led the round to fund that go-to-market push.

## 9. Perplexity details Brain, its self-improving memory system, and Agent API memory tests
[TPS Report](https://tpsreport.news/news/perplexity-brain-memory-architecture-agent-api-testing)
Why it matters: Brain organizes past work and corrections into an evolving knowledge wiki, and Perplexity frames the right test for any memory system as whether stored context actually improves later work, a standard LegCli handoff claims should be held to.

## 10. Revenium joins the Agentic AI Foundation as MCP adoption outruns cost accountability
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/11/02/3393340/0/en/revenium-joins-agentic-ai-foundation-aaif-as-mcp-adoption-outruns-agent-cost-accountability.html)
Why it matters: Revenium brings per-event agent cost attribution into the AAIF observability working group, which matters because every MCP tool call carries a price and nobody can govern agent spend without tracing it to the execution that triggered it.
