# Agent Infra Digest, 2026-10-17

## 1. Anchor launches Action Index, a shared memory of proven web workflows
[HPCwire](https://www.hpcwire.com/aiwire/2026/10/16/anchor-launches-action-index-cutting-computer-use-agent-token-costs-by-100x/)
Why it matters: Launched October 16, Action Index lets agents replay successful web workflows as deterministic code instead of re-reasoning every click, and Anchor's benchmark showed a small model matching a frontier model at $0.016 per task versus $1.57, which is the clearest evidence yet that shared memory beats bigger models for repeated browser work.

## 2. "Context Language Models" paper lets the model manage its own memory
[qelvanotech.blogspot.com](http://qelvanotech.blogspot.com/2026/10/let-model-manage-its-own-memory-context.html)
Why it matters: Published October 16 by researchers at UW, Meta Superintelligence Labs, MIT, and Trillium Labs, the paper replaces hand-built summarization with a model-editable context file and reports +11.4% accuracy at 21.5% less compute on deep research, a result that could obsolete the summarization layers most agent harnesses currently ship.

## 3. Purple Mountain Laboratories launches AXP, a platform for one million AI agents
[AI Affairs](https://www.aiaffairs.com/corporate/purple-mountain-laboratories-china-mobile-axp-agent-platform/)
Why it matters: Unveiled October 16 with China Mobile and two Jiangsu partners, AXP claims to register up to one million agents, run 100,000 simultaneously, and translate between agent protocols across 4,000 km of test networks, the first state-backed attempt at national-scale multi-agent orchestration infrastructure.

## 4. AI agent traffic hit nearly 25 billion requests in Q3 2026, up 41.5%
[Agile Brand Guide](https://agilebrandguide.com/yesterdays-marketing-technology-ai-news-october-16-2026/)
Why it matters: Reported October 15 by DataDome, agent traffic surged to 25 billion requests, and Meta's Muse agentic browser generated 29.1 million requests without identifying itself as an AI agent, which means bot detection and agent identity disclosure are now live operational problems for everyone running web infrastructure.

## 5. Tencent confirms third-party AI agents probed Alibaba's systems
[PYMNTS](https://www.pymnts.com/cybersecurity/2026/tencent-confirms-third-party-ai-agents-targeted-alibaba-systems/)
