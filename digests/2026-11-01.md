# Agent Infra Digest, 2026-11-01

## 1. DeepSeek ships an MIT-licensed super-agent prototype for GitHub repos
[AI Affairs](https://www.aiaffairs.com/technology/deepseek-harness-super-agent-coding-prototype/)
Why it matters: a resident Router fans permitted requests out to isolated Worker sessions that return pull requests to the original conversation, and it hit roughly 4,100 stars in its first day, which shows how much demand there is for open, self-hostable coding agent infrastructure.

## 2. Vercel Labs releases agent-desktop, computer use for any coding agent
[Daily Agentic](https://dailyagentic.info/article/vercel-s-agent-desktop-ai-agents-on-3-oses)
Why it matters: the free, Apache 2.0 tool drives desktop apps on macOS, Windows, and Linux through the accessibility tree with no model inside, so any coding agent gains computer use without a vendor lock-in layer.

## 3. OpenAI SDK 3.42.0 moves agent context compaction to the client
[Emergent](https://emergent.sh/news/openai-sdk-3-42-0-adds-agent-context)
Why it matters: developers can now choose background or blocking compaction for beta agents, sessions, and scheduled runs, turning mid-run summarization from opaque server behavior into a programmable knob, which is exactly the session management surface LegCli cares about.

## 4. Sema4.ai 3.0 adds shared workspaces and claims 80% token savings
[Emergent](https://emergent.sh/news/sema4-ai-3-0-cuts-llm-token-usage-80-shared)
Why it matters: team workspaces for co-managing agents, skills, memories, and files plus forensic audit logs with before-and-after diffs show enterprise agent platforms converging on shared context and full auditability as the selling points.

## 5. OpenCode 2.2.3 routes Claude subscriptions through the Agent SDK
[CellCog](https://cellcog.ai/blog/opencode-claude-subscription/)
Why it matters: OpenCode runs the user's installed Claude Code binary through Anthropic's own Agent SDK without copying the login, reopening a door Anthropic closed in January, and Anthropic has said nothing public about whether it is approved, so this is a live terms-of-service fault line for third-party harnesses.

## 6. Tadpole: a from-scratch LLM agent post-trained on a 4B model
[Emergent](https://emergent.sh/news/tadpole-llm-agent-built-scratch-post-trained)
Why it matters: built without commercial API wrappers and shared openly on GitHub, it is a transparent look at custom agent architecture optimized for tool use, planning, and task decomposition rather than general conversation.

## 7. Trusty Tools v1.11.1 tightens session tracking and memory management
[Undercode News](https://undercodenews.com/trusty-tools-just-got-a-major-update-v1111-strengthens-ai-agent-orchestration-memory-management-and-search-reliability-video/)
Why it matters: recording the parent session whenever a session spawns through the bridge, plus a memory subsystem refactor, attacks the exact debugging pain of multi-agent setups where spawned agents lose their lineage.

## 8. Claude Code gains a server-side rule against rebuilding specific games
[Indie Tooling](https://indietooling.com/posts/claude-code-game-clone-rule)
Why it matters: Anthropic added two sentences to the Opus 5.5 prompt, with no opt-out, steering Claude Code away from recreating a named game even under a new name, a reminder that harness behavior can change overnight by server-side prompt edit.

## 9. Less memory, more wiki: a shared wiki beats heavier agent memory
[Medium](https://medium.com/@siimtolk/less-memory-more-wiki-how-my-ai-agents-got-up-to-3-faster-on-4-fewer-tokens-623b965858cd)
Why it matters: a nightly-generated brief from a shared wiki let two home agents answer all 22 real setup questions correctly, 2 to 3 times faster and on a quarter of the tokens, which argues that curated, always-loaded context beats fetching from a memory database at decision time.

## 10. Mintive raises $7M for its AI agent gateway
[We Are Main Street](https://wearemainstreet.org/world/us/2026/10/29/mintive-raises-7-million-ai-agent-gateway)
Why it matters: the Cowboy Ventures-led seed funds a gateway for MCP interactions that authorizes and manages cloud service access and agent actions, and with 50 enterprise customers already, governed agent access is proving to be a fundable layer on its own.
