# Agent Infra Digest, 2026-11-25

## 1. Claude Code 2.1.332 adds skills from MCP servers in beta
[Gradually](https://www.gradually.ai/en/changelogs/claude-code/)
Why it matters: skills published by an MCP server now show as server:skill in the slash menu, so a server can ship reusable behavior alongside its tools, and the new PreSkillShellCommand hook lets teams refuse a skill's inline shell commands before they run.

## 2. Zipher raises $53M to let agents run enterprise data workloads
[Business Wire](https://www.businesswire.com/news/home/20261124091381/en/Zipher-Raises-$53M-to-Rebuild-Data-Infrastructure-for-Agents-by-Agents)
Why it matters: the seed and Series A rounds from TLV Partners, Maor Investments, and Glilot Capital back agents that pick compute engines, frameworks, and schedules per workload against a budget, so data infrastructure becomes something agents operate rather than something they query.

## 3. Amazon buys Decart's optimization stack and team for a reported $7.5B
[About Amazon](https://www.aboutamazon.com/news/company-news/amazon-decart-ai-optimization)

## 4. Supertake raises $20M seed to turn market theses into agent-run portfolios
[TechCrunch](https://techcrunch.com/2026/11/23/supertake-raises-20m-to-let-ai-agents-turn-your-market-predictions-into-stock-portfolios/?ref=thesaasnews.com)

## 5. Copilot CLI 1.0.115 removes the AUTO_APPROVAL flag and tightens sandboxing
[AgentVera](https://agentvera.dev/en/agent-changelog/)
Why it matters: only managed policy can now disable Assisted Permissions, Windows sandbox package queries turn on by default, and Gemini 4 Hydrogen joins the model picker, which moves Copilot CLI further toward enterprise policy control and away from per-user escape hatches.

## 7. Moody's adds zero-copy data sharing alongside its MCP connectors
[Business Wire](https://www.businesswire.com/news/home/20261124576443/en/Moodys-Embeds-Connected-Intelligence-in-the-Platforms-Where-Customers-Build-With-AI)

## 8. Mesh launches Mesh MCP, turning one prompt into a payments integration
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261124sf05374/mesh-launches-mesh-mcp-turning-one-prompt-into-a-payments-integration)
Why it matters: the hosted MCP server lets a coding agent build a payments, deposit, or wallet-verification integration from Mesh's live API spec with every request validated before it goes out, and it stays read-only and never moves funds, so payment integration becomes an agent task with the risk designed out.

## 9. Archive Intel launches an MCP server and a Claude Compliance API integration
[Business Wire](https://www.businesswire.com/news/home/20261124959125/en/Archive-Intel-Launches-Model-Context-Protocol-MCP-and-Claude-Compliance-API-Integration)

## 10. Leash Biosciences raises $11M to build training environments for scientific AI
