# Agent Infra Digest, 2026-10-08

## 1. Nous Research closes $90M Series B at $1.5B, pushes Hermes agent into the enterprise
[TechCrunch](https://techcrunch.com/2026/10/07/nous-research-confirms-it-hit-1-5b-valuation-launches-ai-agents-for-business-users/)
Why it matters: An open-source agent cloned 24M times and driving a claimed 2.5% of global AI token usage is going enterprise with "Hermes for Businesses", a live test of whether developer adoption of open agent software converts into corporate contracts and $100M of projected year-end revenue.

## 2. Microsoft gives Copilot local file context and OS-wide actions on Copilot+ PCs
[Unite.AI](https://www.unite.ai/microsoft-gives-copilot-local-file-context-and-os-wide-actions/)
Why it matters: Copilot gets on-device context from user files and recent activity, cross-OS actions, and local model access, which moves the agent's working memory from the cloud onto the device where the user's files live.

## 3. Atlassian adds "multi-player" agent collaboration and expands shared context
[TechTarget](https://www.techtarget.com/it-infrastructure/news/366651938/Atlassian-adds-multi-player-agent-collaboration-expands-context)
Why it matters: The Agent Multiplayer Protocol lets agents draw on Atlassian's Teamwork Graph with shared enterprise context, a direct counter-bet to headless agents: collaboration between agents and humans inside workflows, not agents running alone behind an MCP interface.

## 4. AIBound launches AgentHarness, enforcing security policy inside AI agents
[EIN Presswire](https://emergencyservices.einnews.com/pr_news/945841647/aibound-launches-agentharness-security-policy-enforced-inside-ai-agents)
Why it matters: Hundreds of allow/ask/deny rules ship inside the agent itself rather than at the gateway or EDR layer, treating the agent as the most privileged user in the enterprise and putting governance at the decision point.

## 5. Bento Engine launches an MCP layer for compliant financial advice content
[Business Wire](https://www.businesswire.com/news/home/20261007927574/en/Bento-Engine-Launches-MCP-Layer-Giving-AI-Agents-Direct-Access-to-Compliant-Advice-Content)
Why it matters: Wealth-management content that must stay regulator-safe is now directly consumable by agents, a pattern other regulated industries will copy: compliance as an MCP server, not as a review queue.

## 6. AlphaSense launches SuperAnalyst, an always-on agent for financial workflows
[GlobeNewswire](https://rss.globenewswire.com/news-release/2026/10/06/3375733/0/en/alphasense-launches-next-generation-ai-agent-superanalyst-to-power-high-value-financial-and-strategic-workflows.html)
Why it matters: Persistent context plus auditable evidence for 24/7 workflow execution makes memory and monitoring the sell in high-stakes research, which is exactly the trust story enterprise agent platforms have to win.

## 7. Zetaris launches a data harness for agents to query enterprise systems in place
[RuntimeWire](https://runtimewire.com/article/zetaris-cloud-ai-data-harness-launch)
Why it matters: Querying scattered enterprise data where it lives instead of centralizing it first attacks the main blocker between agent prototypes and production, and claims up to 67% lower total cost of ownership.

## 8. Tinuiti opens its measurement layer to any agent with the Bliss Point MCP server
[Adweek](https://www.adweek.com/adweek-wire/tinuiti-unveils-bliss-point-mcp-server-pioneering-open-measurement-access-for-ai-agents/)
Why it matters: One of the first agencies to expose proprietary media intelligence over MCP bets that agent interoperability beats walled gardens, and a single taxonomized view of performance becomes what agents reason over.

## 9. Ramp veterans raise $25M for Melius, a creative-work agent platform
[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/ramp-veterans-raise-25-million-for-ai-creative-platform-melius/)
Why it matters: A team that scrapped its first six months of code to chase creative agents says the product is a set of agents that do the labor of getting an idea out of your head, which is the consumer-friendly wrapper on multi-agent orchestration getting funded right now.
