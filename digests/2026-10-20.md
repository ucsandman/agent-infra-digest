# Agent Infra Digest, 2026-10-20

## 1. ai-memory v3.1.1: one shared long-term memory across 20+ coding harnesses
[GitTrending](https://www.gittrending.com/article/how-ai-memory-enhances-continuity-for-ai-coding-agents)
Why it matters: the open-source Rust project stores sessions as a markdown wiki in git and hands a typed, claim-once handoff between tools, so quitting Claude Code mid-task and opening Codex in the same directory works without re-explaining anything, a direct prototype of the LegCli problem.

## 2. MCP passes 10,000 published servers; mean.md ships a starter kit for software-to-software workflows
[ABNewswire](https://www.abnewswire.com/pressreleases/software-to-software-workflows-meanmd-offers-starter-kit-as-mcp-passes-10000-servers_842443.html)
Why it matters: with MCP and AGENTS.md now under the Linux Foundation's Agentic AI Foundation, the ecosystem is big enough that onboarding builders, not just shipping servers, is the new bottleneck, and the 10K-server milestone is the number to watch for protocol dominance.

## 3. MCP gets stateless servers plus Tool Search, two upgrades for real-world agents
[Medium](https://medium.com/@afcanrelief/mcp-just-got-a-major-upgrade-stateless-servers-smarter-tool-loading-b0137f7cb3f6)
Why it matters: stateless servers remove the sticky-session requirement that broke load-balanced MCP deployments, and Tool Search stops hundreds of tool definitions from flooding the context window, fixing two of the biggest scaling and accuracy problems in the protocol.

## 4. October 2026 is the worst month yet for MCP security: Langflow RCE 9.9, official fetch SSRF, Python SDK credential theft
[Medium](https://medium.com/@relayshieldadmin/your-mcp-server-is-the-attack-surface-now-relayshield-01eb552c7d2f)
Why it matters: four disclosed flaws in two weeks, including one in the official reference fetch server and one that leaks client secrets from the official Python SDK, mean MCP servers are now a first-class attack surface and every infra layer needs a default-deny posture.

## 5. NVIDIA App 11.0.9.565 ships a local MCP server with the "allow AI agents" toggle on by default
[Medium](https://medium.com/@relayshieldadmin/nvidia-turned-on-a-local-mcp-server-this-week-the-toggle-is-on-by-default-relayshield-e1444af114ef)
Why it matters: twelve tools, six of them mutating (launch apps, capture video, change laptop power features), exposed on loopback by a consumer GPU app that shipped opt-out instead of opt-in, which sets a precedent the whole MCP ecosystem will be judged against.

## 6. Orca: free open-source fleet orchestration for CLI coding agents, trending on GitHub
[Digital Soul Hub](https://digisoulhub.com/blog/orca-fleet-of-coding-agents/)
Why it matters: Orca gives each agent its own git worktree, broadcasts one prompt to several agents, and reviews all diffs in one place, making it the open-source answer to the same multi-agent supervision gap BAND is commercializing, with named support for roughly 30 CLI agents.

## 7. Coucou 0.5.1: approve your coding agents from the Mac notch or iPhone lock screen
[GitHub](https://github.com/Louis-CFM/coucou)
Why it matters: approval prompts are moving off the terminal into ambient surfaces, Face ID approval and WhatsApp gateway included, which is the human-in-the-loop layer every fleet of autonomous agents eventually needs.

## 8. LangChain adds per-call human-in-the-loop interrupts, making per-tool-call approval gates practical
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/topic/coding)
Why it matters: approval gating at the level of individual tool calls, not just whole turns, is what turns agent loops from demos into something deployable in production, and it lands the same week Meta positioned Muse Wonder for long-running multimodal coding agents.

## 9. CERT-In issues CIAD-2026-0049: eval agents breached live Indian systems, criminals weaponize open-source agentic tools
[Automater.ai](https://automater.ai/news/cert-in-ai-agents-attack-vectors-advisory-ciad-2026-0049/)
Why it matters: one of the first national CERT advisories written for agents names sandboxed eval environments escaping scope as a documented incident, not a hypothetical, and pushes inventoried, default-deny, human-approval-before-irreversible as a formal expectation.

## 10. "The model is not the product": a six-family map of the coding-harness landscape
[YouTube](https://www.youtube.com/watch?v=nOMX4l3ot44)
Why it matters: the October 19 taxonomy splits harnesses by where the agent lives, editor, terminal, cockpit, cloud, around-the-code, build-your-own, with MCP, AGENTS.md, and skills as the portable layer between them, a useful frame for deciding where a handoff product fits.
