# Agent Infra Digest, 2026-11-03

## 1. DeepSeek open-sources Super-agent, a proactive coding agent that watches your repo and chats
[Nowrap](https://nowrap.ai/news/deepseek-super-agent-coding-prototype)
Why it matters: a long-lived Router session dispatches work to isolated Worker sessions driven by chat, PR, and CI events instead of prompts, and DeepSeek's own test cut p95 task time nearly in half at 2 to 4 times the token cost, which frames the next harness tradeoff as attention saved versus tokens spent.

## 2. Uber details its MCP Gateway running 800-plus servers and 5,000-plus tools
[Uber Engineering](https://www.uber.com/us/en/blog/designing-mcp-gateway/)
Why it matters: a Registry control plane plus a Proxy Gateway data plane, with tools disabled by default until owners enable them and an Omni MCP proxy that keeps the full catalog out of the context window, is the clearest production template yet for MCP at enterprise scale.

## 3. Vercel Labs open-sources agent-desktop, computer use over accessibility trees instead of pixels
[Coddykit](https://www.coddykit.com/pages/blog-detail?id=5130015&slug=github-trending-november-2026-from-an-8k-star-rust-desktop-agent-to-a-92k-star-w)
Why it matters: stable accessibility-tree references make desktop actions safe to retry, and the Rust tool hit 8,400 stars in a day, a sign that reliable execution, not smarter models, is where open-source agent energy is going.

## 4. NVIDIA publishes Auto Ontology, a semantic layer that serves databases to agents over MCP
[ExplainX](https://explainx.ai/blog/nvidia-auto-ontology-open-source-context-layer-agents-mcp-text-to-sql-2026)
Why it matters: building a business-meaning ontology over Databricks, Postgres, Snowflake, and DuckDB and serving it through MCP, CLI, and API attacks the text-to-SQL context problem at the catalog level, though the repo is NVIDIA-internal today and needs GitHub credentials to install.

## 5. GitHub makes Copilot Fusion generally available, routing and orchestrating models per task
[Unite.AI](https://www.unite.ai/github-makes-copilot-fusion-generally-available-at-universe-2026/)
Why it matters: Fusion picks Single, Cascade, or Critique execution per prompt and scored 60 on the Artificial Analysis Coding Agent Index at about half the cost of Claude Code with Opus 5.5 Max, so model selection itself is becoming a platform feature rather than a developer decision.

## 6. Copilot Projects turns Copilot into a multi-agent workspace across repos
[DEV](https://dev.to/delimitter/github-turns-copilot-into-a-multi-agent-workspace-with-new-projects-feature-5lh)
Why it matters: parallel agents working across multiple repos with Slack threads, mocks, and meeting notes as context moves session management from one chat window to a managed fleet, which is exactly the coordination problem LegCli's handoff has to survive.

## 7. Mintive raises a $7M seed for agent identity and governed deployment
[Your Info Daily](https://www.yourinfodaily.com/p/mintive-raises-7m-seed-led-by-cowboy-ventures-for-ai-agent-identity)
Why it matters: the former MintMCP pairs an MCP gateway with scoped, revocable agent credentials delegated from a person, and with Jeff Dean and Andrej Karpathy as angels plus 50 paying customers since February, agent identity is now a funded category, not a checklist item.

## 8. Infisical raises a $40M Series B at a $600M valuation for agent credential security
[Capvise Media](https://media.capvise.group/story/infisical-series-b-40-million-agent-security-october-2026/)
Why it matters: its Agent Vault lets agents access systems without ever seeing raw keys, and a $600M valuation for secrets tooling aimed at agents says the market expects credential brokerage to be core agent infrastructure.

## 9. LangChain ships Managed Deep Agents v0.10 with a sandboxed browser and background subagents
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/topic/coding)
Why it matters: browser tools with a human handoff for sign-in plus async subagents mean long-running agent tasks no longer block the conversation, pushing managed-agent platforms toward the same background-session model every harness builder is converging on.

## 10. MetaHarness launches at GitHub Universe as an open-source factory for agent harnesses
[AI Agent Store](https://aiagentstore.ai/ai-agent-news/topic/agent-collaboration)
Why it matters: scaffolding CLI tooling, scoped memories, witness-signed releases, and red/blue testing in one generator treats harness safety and auditability as defaults, raising the bar for any new harness that ships without them.
