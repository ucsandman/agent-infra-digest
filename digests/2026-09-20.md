## 4. Plugin4Shell: zero-click RCE that bypasses SHA pinning across Claude Code, Codex, Copilot, and Gemini CLI
[Forkast](https://forkast.news/plugin4shell-bypasses-sha-pinning-across-all-four-major-ai-coding-agents/)

## 5. Agent Memory Challenge 2026 Cycle 2 opens September 20 with a shared evaluation for long-term agent memory
