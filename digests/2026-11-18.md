# Agent Infra Digest, 2026-11-18

## 1. Cognition launches Devin Bots, persistent agents that manage teams of Devins
[AI Weekly](https://aiweekly.co/alerts/cognition-launches-devin-bots-to-oversee-teams-of-devin-agents)
Why it matters: each Bot owns a goal for days or weeks, keeps memory across the whole project, and delegates to parallel Devin sessions, so the coding agent moves from ticket executor to manager, with Cognition claiming one Bot built its Android app in 44 days.

## 2. OpenAI releases GPT-6.2 Astra and Sol for ChatGPT Work and Codex
[Digital Today](https://www.digitaltoday.co.kr/en/view/127103/openai-releases-gpt-6-2-astra-and-sol-for-chatgpt-work-and-codex)
Why it matters: Astra is 20 percent cheaper than GPT-6 Astra at $8/$40 per million tokens while Sol lands within half a point of Astra on FrontierCode 2.0 at a fifth of the cost, so the agentic coding model market now has a cheaper frontier and a cheaper everyday tier from the same vendor.

## 3. Claude Code 2.1.327 guards GitHub installs and MCP config edits
[Subagentic](https://subagentic.ai/posts/claude-code-2-1-327-mcp-guards/)
Why it matters: the November 17 release puts a confirmation in front of repository changes from /install-github-app, reads MCP server JSON from stdin so tokens stay off the command line, and stops project-scoped MCP edits from wiping other keys in .mcp.json, which closes three config-safety holes in one patch.

## 4. Microsoft and Salesforce announce Copilotforce, connecting Salesforce to Copilot over MCP
[The Agile Brand Guide](https://agilebrandguide.com/yesterdays-marketing-technology-ai-news-november-18-2026/)
Why it matters: announced at Microsoft Ignite on November 17, the integration brings Salesforce data and actions into Copilot, Teams, and Fabric through authenticated MCP access with 38 prebuilt sales skills, so the two biggest enterprise platforms now interoperate through the agent protocol instead of a custom connector.

## 5. OpenCode Browse hands coding agents your signed-in browser
[Emergent](https://emergent.sh/news/opencode-browse-gives-ai-agents-your-signed)
Why it matters: the MCP server and Chromium extension lets Claude Code, Cursor, Codex, and Zed drive your real browser with tabs, logins, and extensions intact, which replaces headless workarounds with live-session control and raises the stakes on what an agent can do with your authenticated accounts.

## 6. Pulsar puts every coding agent on your Mac on one local message bus
[Medium](https://medium.com/@iamsupcat/i-let-claude-code-and-opencode-hand-work-to-each-other-with-pulsar-on-a-macbook-or-mac-mini-it-549dc0c8d23b)
Why it matters: the free, local, MIT-licensed tool lets Claude Code, OpenCode, Codex, Cursor, and Gemini CLI hand work to each other and wake idle agents, so multi-agent handoffs become a local protocol instead of a cloud service, with a day-one bug where a cancelled wait can drop a message.
