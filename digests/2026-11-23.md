## 8. Tether replays an agent run offline, event for event, at zero model cost
[LLM Digest](https://www.llm-digest.com/daily)
Why it matters: the Rust harness routes every model and tool call through a policy check and a trace that replays deterministically without calling a model, so agent runs become debuggable and auditable artifacts instead of one-off, unrepeatable sessions.
