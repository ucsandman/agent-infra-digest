# Agent Infra Digest, 2026-09-16

## 1. Factory raises $200M at a $5B valuation
[Reuters](https://www.reuters.com/business/ai-coding-agent-startup-factory-triples-valuation-5-billion-latest-funding-round-2026-09-15/)
Why it matters: Enterprise coding agents are now a $5B category. Factory tripled its valuation in five months, and Cognition raised $2B earlier this month. The money is chasing agentic software factories, not chatbots.

## 2. OpenAI launches managed Agents API in public beta
[InfoWorld](https://www.infoworld.com/article/4221163/openai-launches-managed-agents-api-to-simplify-enterprise-ai-agent-development.html)
Why it matters: OpenAI is productizing the Codex harness as a one-call API, with sandbox options from Cloudflare, Daytona, E2B, Modal, Runloop, and Vercel. Managed harnesses are becoming the default enterprise on-ramp, which raises the bar for any self-hosted alternative.

## 3. MCP gets its biggest update ever, with a 12-month deprecation guarantee
[VentureBeat](https://venturebeat.com/infrastructure/mcp-just-got-its-biggest-update-ever-heres-what-changes-for-ai-agents)
Why it matters: The formal deprecation policy (12 months minimum between deprecation and removal, shaped with input from Google, Microsoft, and Amazon) is the stability contract enterprises needed. MCP is moving from wild-west protocol to enterprise standard.

## 4. Agentic AI Foundation launches MCPA certification for MCP expertise
[PR Newswire](https://www.prnewswire.com/news-releases/agentic-ai-foundation-launches-mcpa-certification-to-validate-mcp-expertise-302877134.html)
Why it matters: The first vendor-neutral MCP credential, announced at AGNTCon + MCPCon Europe this week. MCP Tier 1 SDK downloads are approaching half a billion per month. The ecosystem is now big enough to need its own certified labor market.

## 5. Tencent launches Team Memory beta: shared agent memory across a team
[VentureBeat](https://venturebeat.com/data/tencents-team-memory-shares-ai-agent-memory-across-a-team-with-no-governance-yet-for-when-its-wrong)
Why it matters: Moves the memory problem from one agent's session to a shared team hub with access controls. Directly relevant to LegCli's world: whoever owns cross-session, cross-agent context owns the handoff layer. The governance gap they flag (a wrong fact now costs the whole team) is the same trust problem session handoffs face.

## 6. Salesforce Agentforce gets a long-horizon runtime for multi-day agent work
[Salesforce](https://www.salesforce.com/ap/news/press-releases/2026/09/14/sg-salesforce-expands-agentforce-with-a-new-portfolio-of-ai-agents-built-for-high-value-work/)
Why it matters: Memory, durable execution, and dynamic steering so agents can pursue goals across days and weeks. Long-horizon work makes session continuity a first-class platform feature, which validates the problem LegCli solves at the developer layer.

## 7. MCP Python SDK v2.0.0 renamed FastMCP to MCPServer with no shim, breaking servers silently
[DEV Community](https://dev.to/justhsnn/why-your-mcp-server-breaks-silently-when-the-sdk-renames-things-underneath-you-5b8a)
Why it matters: A cautionary tale for anyone shipping MCP servers (including leg-alexa-mcp): unpinned `mcp` dependencies silently resolve to the renamed 2.x API. Pin your SDK versions and set a version floor.

## 8. ReleasePad launches an MCP server so coding agents can draft and publish changelogs
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/14/3361396/0/en/releasepad-launches-mcp-server-so-ai-agents-can-draft-publish-and-measure-product-changelogs.html)
Why it matters: Another vertical MCP server (Claude, Codex, Grok compatible) with human approval before publish. The MCP server pattern keeps expanding from dev tools into product ops.

## 9. TrueFoundry open-sources TrueForge agent harness, claims up to 75% lower cost
[InfoWorld](https://www.infoworld.com/article/4211969/truefoundry-debuts-open-source-ai-agent-harness-claiming-up-to-75-lower-costs.html)
Why it matters: Open-source harness positioned against Anthropic's Claude Managed Agents, with bring-your-own MCP servers and multi-model support. The cost-per-agent-run conversation is heating up, worth watching for pricing pressure on managed offerings.

## 10. Vercel's Ship: new "eve" open-source agent framework; agents now trigger over half of all deploys
[SiliconANGLE](https://siliconangle.com/2026/06/17/vercel-launches-new-framework-enterprise-controls-agentic-ai-infrastructure/)
Why it matters: Vercel says coding agents went from under 3% to over half of all commits on its platform this year, with AI Gateway token volume up 10x. The agent-built software wave is the demand engine everything else in this digest serves.
