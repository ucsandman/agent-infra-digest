# Agent Infra Digest, 2026-10-25

## 1. Google announces Agent Compute Engine, a microVM per agent
[Tesla News Wire](https://teslanewswire.com/articles/google-agent-compute-engine-hardware-isolated-microvm-ai-agents-preview-agntcon-mcpcon-oct-22-2026)
Why it matters: announced at AGNTCon + MCPCon on October 22, it turns the internal runtime behind Gemini agents into a product, with checkpointed microVMs that pause while the model thinks, which makes long-running agents a managed compute workload rather than a process you babysit.

## 2. Agentic AI Foundation adds four projects from Anthropic, OpenAI, Hugging Face, and Alibaba
[Linux Foundation](https://www.linuxfoundation.org/press/agentic-ai-foundation-announces-four-new-projects-agent-skills-open-responses-openenv-and-opensandbox?hs_amp=true)
Why it matters: Agent Skills, Open Responses, OpenEnv, and OpenSandbox take AAIF from three projects to ten in its first year, which means the agent stack's key layers now have neutral governance instead of living inside one vendor's roadmap.

## 3. AAIF member survey: 89% use or evaluate MCP, 81% have agentic AI in production
[Udienza](https://www.udienza.com/articles/agntcon-mcpcon-north-america-2026)
Why it matters: from 186 member companies, MCP is the most adopted agent standard ahead of Skills at 69% and A2A at 57%, which tells harness builders where the integration effort actually pays off.

## 4. Google Data Agent Kit reaches general availability as an MCP server for cloud data
[WiseVoter](https://wisevoter.com/world/us/2026/10/24/google-launches-data-agent-kit)
Why it matters: coding agents in VS Code, Cursor, Codex, Claude Code, and Antigravity can now query live BigQuery and Bigtable schemas through MCP with IAM-gated guardrails, which moves governed data access from custom glue code to a standard server.

## 5. Coding agent releases stack up: Claude Code 2.1.310, Codex CLI 0.164.0, Amp orbs
[TurboAI](https://www.turboai.dev/)
Why it matters: the October 24-25 releases add a Monitor tool for background work in Claude Code, preset slots and credential masking in Codex, and self-hosted orbs in Amp, which shows the release cadence for coding agents is now daily and the diff that matters is env vars, model IDs, and defaults, not marketing notes.

## 6. deepset and NVIDIA unveil a reference architecture for self-improving sovereign agents
[Morningstar](https://www.morningstar.com/news/pr-newswire/20261021ph77357/deepset-unveils-reference-architecture-for-self-improving-sovereign-ai-agents-on-nvidia-infrastructure)
Why it matters: a second Haystack agent proposes changes to the first agent's harness, evaluated against objectives with approval, audit, and rollback controls, which is the first credible pattern for agents that improve in production without shipping their data to an external API.

## 7. Notified opens an MCP beta for PR and IR workflows
[GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/21/3385795/0/en/notified-opens-model-context-protocol-mcp-beta-program-for-pr-and-ir-data-and-services.html)
Why it matters: press release drafting, optimization, and reporting now work inside Copilot and Teams first, which shows MCP adoption spreading from developer tools into enterprise comms stacks where security review already cleared Microsoft 365.

## 8. Microsoft extends its Power Pages plugin to traditional sites for Copilot CLI and Claude Code
[Windows Forum](https://windowsforum.com/news/power-pages-ai-plugin-adds-traditional-site-support-copilot-cli-claude-code-and-pac-cli-timeline.449813/)
Why it matters: with preview forecast for October 2026 and GA for November, agents can soon create and edit template-driven Liquid-and-forms portals, which brings coding agents into the government and customer-portal estates that SPA-only tooling could not touch.

## 9. Z.ai's ZCode pairs a multi-agent harness with the cheap GLM-5.3-Flash model
[Claw](https://claw.rommark.dev/blog/88-zcode-glm-flash-agentic-coding-use-cases.html)
Why it matters: an Apache-licensed desktop, browser, and terminal harness with goals-based task management and messaging-app control, running a multimodal flash model built for screenshot understanding, is a concrete example of the low-cost agent loop that undercuts frontier-priced coding agents.

## 10. Apple engineers describe moving agents from FastAPI prototypes to Ray on Kubernetes
[My2Cents](https://www.my2cents.ai/news/2026-10-21-architecture/)
Why it matters: multi-turn, stateful agents with parallel tool calls outgrow a standard Kubernetes deployment, and the proposed fix is a control plane for quotas and placement plus eval-gated releases, which is the production pattern most agent teams will hit once they scale past a prototype.
