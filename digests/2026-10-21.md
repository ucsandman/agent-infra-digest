# Agent Infra Digest, 2026-10-21

## 1. Hackers hit AI coding tool OpenCode, running up charges on users' AI accounts
[TechCrunch](https://techcrunch.com/2026/10/19/hackers-hit-ai-coding-tool-opencode-running-up-charges-on-users-ai-accounts/)
Why it matters: a large-scale distillation attack breached OpenCode Console and leaked 1.4% of users' stored API keys, with victims reporting hundreds to thousands of dollars in unauthorized model charges, which proves API key custody is now the single most dangerous part of any agent harness.

## 2. Xcode 26.3 brings agentic coding: Claude and Codex now integrated into the IDE
[DEV Community](https://pengen.diewe.workers.dev/arshtechpro/xcode-263-brings-agentic-coding-claude-and-codex-now-integrated-into-your-ide-1l5p)
Why it matters: Apple shipped first-party agentic coding in Xcode 26.3 RC with Claude Agent, Codex, and custom agents wired through MCP, so the biggest remaining holdout IDE is now an agent runtime and every harness has to plan for Apple's sandbox rules.

## 3. OpenAI and Paradigm release EVMbench as Claude gets blamed for a $2.7M Moonwell bug
[BitRss](https://bitrss.com/openai-releases-crypto-security-tool-as-claude-blamed-for-2-7m-moonwell-bug-185206)
Why it matters: EVMbench tests whether agents can detect, patch, or exploit 120 real smart contract vulnerabilities, and it launched days after AI-generated code cost Moonwell users $2.7M, so agent output is moving from unverified help to liability-grade code.

## 4. CAEVES ships Context LAKE: enterprise context as a managed MCP service
[Forkast](https://forkast.news/caeves-ships-context-lake-enterprise-context-as-a-managed-mcp-service/)
Why it matters: Context LAKE reached general availability as a subscription MCP service that serves permission-filtered enterprise data to agents with ingestion, access control, and masking built in, which is the commercial shape of the memory plus governance layer the whole infra stack is converging on.

## 5. Mural raises $15M in a Tether-led round for AI agent payments
[GenZ NewZ](https://genznewz.com/mural-raises-15m-for-ai-agent-payments-in-tether-led-round)
Why it matters: the round brings Mural to $28M total while it reports $2.1B processed for agents moving money across 128 countries, so payment rails for autonomous agents are now funded like infrastructure instead of an experiment.

## 6. TraceWeave raises $2.27M seed to run AI agents on-device
[Dealroom](https://dealroom.co/news/164524-traceweave-raises-2-27m-seed-to-run-ai-agents-on-device/)
Why it matters: its Phase-TITAN post-Transformer architecture claims constant memory as agent context grows, 0.04GB at 1M tokens versus tens of gigabytes for a Transformer KV cache, which would let agents call tools and decide next steps on-device without cloud calls.

## 7. Codex vs Claude Code: the better coding agent now comes down to cost per completed task
[TechRepublic](https://www.techrepublic.com/article/news-codex-vs-claude-code/)
Why it matters: Artificial Analysis puts Claude Code with Sonnet 5.5 at 68 and Codex with GPT-6.1 Sol at 63 on its Coding Agent Index, but the gap vanishes at matched effort while Codex stays faster and cheaper per task, so pricing, not raw score, is deciding harness choice.

## 8. Liminal expands MCP access to every customer and adds Field Intelligence Feeds
[GlobeNewswire](https://markets.financialcontent.com/dailypennyalerts/article/gnwcq-2026-10-19-liminal-expands-mcp-access-to-every-customer-and-broadens-what-ai-agents-can-reach)
Why it matters: every Liminal platform tier can now connect Claude, ChatGPT, Gemini, or a custom agent directly to licensed market intelligence, which is another data vendor betting that agents, not dashboards, are where decisions get made.

## 9. LINKSPREED ships a native MCP server for its UIID identity protocol
[LINKSPREED](https://web4.medium.com/linkspreed-native-mcp-server-for-uiid-v2-13-e36f67870f91)
Why it matters: UIID v2.13 gives agents a scoped, revocable way to act on a user's behalf without touching raw credentials, which attacks the same over-privilege problem behind the OpenCode breach from the identity side.

## 10. Your AI agent has a memory problem: attackers planted memories that outlived the session
[Medium](https://medium.com/@aliabdullah_2062/your-ai-agent-has-a-memory-problem-here-is-the-fix-d55a1e41d75e)
Why it matters: researchers planted persistent memories in AWS Bedrock AgentCore that kept steering agents after sessions ended, plus memory can lose to full context on accuracy while winning on cost, so any handoff product has to scope memory per agent identity and build selective forgetting from day one.
