# Agent Infra Digest, 2026-10-16

## 1. Aoki infostealer now harvests credentials from AI coding assistants
[cyberpress.org](https://cyberpress.org/aoki-targets-ai-credentials/)
Why it matters: Reported October 16 by Symantec's Threat Hunter team, the Aoki malware now targets local credential and session files for Claude, Codex, Cursor, GitHub Copilot, and others, which means any agent harness storing session tokens on developer machines has a new exfiltration risk and revocation design is now a feature, not an afterthought.

## 2. Crowded launches Crowded MCP for nonprofit finance workflows
[atlanticbrief.com](https://atlanticbrief.com/crowded-launches-crowded-mcp-bringing-nonprofit-financial-operations-into-chatgpt-and-claude/)
Why it matters: Launched October 15, the connector exposes live fund accounting, spend queries, and Form 990 prep inside ChatGPT and Claude, another example of vertical SaaS vendors skipping bespoke AI apps and shipping MCP servers straight into the assistants users already have.

## 3. Egnyte ships Context Studio and AI Control Center
[globenewswire.com](https://www.globenewswire.com/news-release/2026/10/15/3381930/0/en/egnyte-unveils-context-studio-and-ai-control-center-for-more-accurate-secure-and-cost-efficient-ai.html)
Why it matters: Announced October 15, Context Studio lets teams see and tune what business context each agent can access while AI Control Center inventories every agent touching company content, which is the context visibility plus governance pairing that enterprise agent deployments have been missing.

## 4. Claude Code 2.1.299 to 2.1.301 quietly changed how hooks behave
[dev.to](https://dev.to/gabrielanhaia/claude-code-21299-to-21301-changed-how-your-hooks-behave-7-things-to-recheck-373d)
Why it matters: Three releases on October 14 and 15 moved when prompt hooks run, which MCP tools an agent's tool list picks up, and what plugin hooks do when unanswered, so anyone with custom hooks or skills on Claude Code needs to recheck their setup, since behavior changes now ship without waiting for an edit on the user's side.

## 5. RapidCanvas raises $29M Series B for AI data science agents
[tech-insider.org](https://tech-insider.org/rapidcanvas-29-million-series-b-ai-agents-2026/)
Why it matters: Confirmed October 15 and led by Vertex Ventures and Hitachi Ventures, the round bets that industrial and manufacturing buyers are a less crowded lane for agent platforms than general enterprise software, a vertical-first funding signal worth watching.

## 6. Uvi lands $7.5M seed to cut agent operating costs up to 8x
[uxc.news](https://uxc.news/p/uvi-lands-7-5-million-seed-round-to-slash-ai-agent-expenses-with-new-context-reasoning-layer)
Why it matters: Announced October 14, Uvi's context reasoning layer pre-filters prompts before task execution, claiming up to 80% token reduction, which matters because token cost is still the binding constraint on long-running autonomous agents.

## 7. Forgepoint raises $9.8M seed for AI inside sales agents in manufacturing
[wsgr.com](https://www.wsgr.com/en/insights/firm-advises-forgepoint-on-dollar98-million-seed-financing.html)
Why it matters: Announced October 14 and led by Primary Venture Partners and a16z speedrun, Forgepoint's Frank agent handles the RFQ to PO flow with per-shop pricing rules, showing agent startups are finding traction by modeling existing human workflows rather than inventing new ones.

## 8. Axi connects MT5 trading accounts to Claude over MCP
[globenewswire.com](https://www.globenewswire.com/news-release/2026/10/14/3380898/0/en/axi-launches-mcp-integration-connecting-mt5-accounts-to-claude.html)
Why it matters: Announced October 14, traders can query live positions, execute trades, and update risk parameters through natural language, one of the first examples of MCP reaching into a live trading environment where the agent's actions move real money.

## 9. Daily tracker: ServiceNow opens employee-built agents, xAI ships Grok Voice 3.0
[aiagentsdirectory.com](https://aiagentsdirectory.com/news/ai-agents-evolve-enhanced-capabilities-and-emerging-security-concerns)
Why it matters: The October 15 roundup captures two parallel trends, enterprises decentralizing agent building to employees via ServiceNow EmployeeWorks and xAI pushing voice agents with Grok Voice 3.0, while noting agent traffic is surging faster than the security systems that watch it.
