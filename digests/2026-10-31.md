# Agent Infra Digest, 2026-10-31

## 1. GitHub turns Copilot into a multi-agent workspace with Copilot Projects
[DEV Community](https://dev.to/delimitter/github-turns-copilot-into-a-multi-agent-workspace-with-new-projects-feature-5lh)
Why it matters: announced at GitHub Universe, Copilot Projects lets teams assign goals spanning multiple repos and feed agents Slack threads, mockups, and meeting notes as context, which moves the coding agent market from single-task assistance to orchestrated multi-agent development.

## 2. Android Studio Rabbit 2 opens to 40+ third-party coding agents
[TechGig](https://techgig.com/amp/news/ai/google-opens-android-tools-to-third-party-ai-agents/135288250)
Why it matters: Google's Bring Your Own Agent feature, stable in Rabbit 2, runs Claude, Codex, and Antigravity inside the IDE over the open Agent Client Protocol, so the IDE becomes a neutral agent host rather than a single-vendor front end.

## 3. OpenAI rewrites the Model Spec around memory and agent oversight
[AI Daily Post](https://aidailypost.com/news/openai-updates-gpt-guidelines-use-memories)
Why it matters: the revised spec makes memory a first-class behavior while requiring models to separate what users actually said from what they inferred, and it tightens when unsupervised agents may act and what they must disclose first, which is a governance template for anyone building persistent-context products.

## 5. Tencent plugs WorkBuddy into enterprise systems over MCP
[Computer Weekly](https://www.computerweekly.com/news/366653072/Tencent-plugs-WorkBuddy-into-enterprise-systems)

## 6. Airbyte ships an MCP server for talking to data pipelines

## 7. VIAVI adds an MCP server framework to its network test portfolio

## 9. ZoomInfo puts its data inside Snowflake Cortex Agents via MCP
